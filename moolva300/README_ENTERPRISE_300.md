# MoOLVa ХАССП Easy 3.0 Enterprise · Windows · один компьютер

## Назначение
Локальная система для одной рабочей станции предприятия питания.
Сохраняет SQLite-базу и существующие журналы, ТТК, склад, документы, оборудование,
мастер создания предприятия, историю действий и локальные учётные записи.

## Новый рабочий экран «Рабочий день 3.0»
- Выбор сотрудника из действующего списка предприятия и просмотр его сменных задач.
- Статистика графиков и просроченных задач только на основании сохранённых данных.
- Планы будущих заполнений на 1–31 рабочих дней с пропуском выходных.
- Повторное создание того же плана не дублирует строки.
- Передача смены: отправитель, получатель, свободное сообщение, аудит.
- Учебные подсказки с отдельным подтверждением «прочитано».
- Локальный справочный помощник, использующий проверенные правила; без сетевого API.
- Поиск среди графиков журналов, документов и сотрудников.
- Проверка SQLite PRAGMA quick_check и количества записей/событий аудита.
- Прямые переходы в существующие модули: журналы, склад, ТТК, меню, отклонения,
  документы, оборудование, настройки, мастер предприятия.

## Безопасность
Ни планирование, ни учебная отметка, ни ответы помощника не создают фактических
измерений, дат осуществлённых проверок, подписей, результатов аудита или списаний.
Фактические операции остаются за ответственным сотрудником.

## Корпоративные улучшения (15 блоков)
Мастер предприятия и настройка журналов — существующий мастер 2.2.2/2.3;
рабочий стол по сотруднику, обучение и передача смены — новые в 3.0;
склад, партии, ТТК и меню — существующие модули;
документы, оборудование, отклонения, аудит, диагностика, резервирование,
права доступа и многопредприятие — действующие функции с дополнительными
переходами из единого рабочего экрана.

## Ограничения
- Работа только на одном Windows-ПК, не многопользовательский сервер.
- Помощник справочный, **не генеративный ИИ**, не принимает юридических решений.
- Новые функциональные возможности и первоначальные модули ещё требуют
  приёмочной проверки на реальном предприятии перед производственной эксплуатацией.
- Установщик не имеет доверенной коммерческой цифровой подписи издателя.
- Сроки и применимость обязательных журналов определяются самим предприятием
  по применимым требованиям и утверждённой программе производственного контроля.

## Проверка выпуска
Workflow `.github/workflows/moolva-enterprise300.yml` выполняет Windows-тесты,
создание настоящего WPF+WebView2 приложения, упаковку Python backend, запуск без
установленного Python, тест обновления/отката и пробную установку Windows.
До статуса GitHub Actions Success выпуск считается кандидатом.

## Хранение данных
Пользовательская база: `%LOCALAPPDATA%\MoOLVaHACCPStudio\haccp.sqlite3`.
Приложение не пересоздаёт существующую базу.
Перед обновлением рекомендуется сделать внешнюю копию (вместе с резервной копией
из программы) и проверить возможность восстановления.

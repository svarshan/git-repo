# MoOLVa 8.0 PRO MAX — «Орнитологический интеллект»

Разработано поверх Windows 7.9 с сохранением всех прежних функций, исторических релизов и пользовательских форматов.

1. Bird Vision AI: реальная EfficientNet ONNX модель из репозитория chriamue/bird-species-classifier (MIT), 525 классов, pinned revision ff5136258c85e15098b4db44ba00a8fdcf2d04d5, pinned SHA256. Фотография остаётся на компьютере. Подписи классов из исходного config.json. Соответствия с 298 видами каталога только по явно заданным проверенным названиям.
2. Bird AI 7.0: офлайн Perch v2, анализ нескольких фрагментов, предупреждение о слишком слабом и клиппированном звуке.
3. Центр 3 в 1: фото + голос + подтверждённые признаки из локальной энциклопедии. Баллы совпадений не считаются вероятностями.
4. Карта: населённый пункт, сезон, укрупнённые опубликованные GBIF-зоны, без обещания присутствия и координат гнёзд.
5. Голоса: цель 298, поиск только лицензированных аудио, честный CSV недостающих записей.
6. Энциклопедия: все прежние карточки/фото/голоса и поисковая связка с новым центром.
7. Дневник: статистика по годам и месяцам, CSV, сохранены личные вложения и архивы.
8. Академия 4.0: реальные фото/голоса, уровни, отдельные результаты и достижения.
9. Производительность: отложенная загрузка моделей и медиа, прежняя оптимизация галереи.
10. Сертификация: тесты Node/Python, нативная Perch v2 и Bird Vision диагностика в упакованном Electron, семь настоящих скриншотов, QA, SHA256 и список недостающих голосов.

**Ограничения:** точность 525-классовой модели на региональных 298 видах не подтверждена независимым тестовым набором. Наличие реальной модели не гарантирует правильное определение каждого регионального вида. Отдельно требуется ручная проверка микрофона, личных архивов и Windows GUI на устройстве пользователя.

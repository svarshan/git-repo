# MoOLVa 7.8 PRO MAX — «Живая природа 2.0»

This release extends the real 7.7 offline Windows app. Existing releases are not rewritten.

1. **Bird AI 5.0**: existing authentic Perch v2 ONNX Windows model, real multisegment predictions, context message when scores are close, top-three timeline, manual validation required. No invented probability and no multi-bird certainty claim.
2. **Voices COMPLETE (298 goal)**: existing licensed iNaturalist/Xeno-canto/Commons ingestion continues with technical audio QA and truthfully reported shortfall. No fabricated sounds or promises of 298.
3. **Encyclopedia ULTRA**: offline tabs for original full source article, excerpts matching recognition-related terms, same-genus birds for comparison, GBIF seasonal observations. No guessed size/characteristics; source attribution linked.
4. **Atlas ULTRA 5.0**: seasonal/group filtering remains; newly visible source density, most recent selected observation year, and low-coverage caution derived from recorded GBIF zones. No precise nests or live predictions.
5. **Premium 4.0**: adjustable global reading size, card sizes, fullscreen photo, existing tidy collapsible/optional pinned sidebar preserved.
6. **Audio Lab 4.0**: dual authentic local tracks, independent playback, selectable rate, real realtime frequency-bin visualization; not pre-rendered fake spectrograms.
7. **Field diary 5.0**: custom date and text filter, stats for observed species/places and counted individuals, legacy expedition/attachment UI preserved.
8. **Backup PRO**: one validated offline JSON snapshot of allowlisted settings, legacy journal and IndexedDB attachments; restoration validates whole archive first, asks for confirmation, retains absent keys. Archives up to 65 MiB, attachments total under 44 MiB. *Partial IndexedDB writes may remain if a later storage failure occurs; always keep source archive.*
9. **Performance MAX**: existing lazy calendar/gallery, optional audio media preload='none', CSS-only card resizing, no added network calls, no new model downloads.
10. **Windows Quality Gate**: regression tests for pure tools and source integration, JS syntax, Python catalog checks, native Perch smoke test, Setup+Portable x64, SHA-256, versioned GitHub Release.

Test and verify on a real Windows computer before relying on microphone/device behavior and backups. The UI is offline by CSP; external original-source links are annotations to be consulted independently.

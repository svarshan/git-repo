# MoOLVa 8.6 — 21 оставшийся голос (исследование 2026-11-04)

Статус: **кандидаты на записи**, не 21 новых аудиофайл. Итог последнего завершённого этапа: 277/298 (265 исходных + 12 добавленных). Без проверки реальной Windows-сборки и итогового coverage.json не объявлять новый прогресс.

## Правила
- Исходные 265 аудиофайлов не заменять; сверять SHA-256 с `data/voice-baseline85.json`.
- Сверять латинское название, источник и *лицензию конкретного файла*, имя автора; сохранять атрибуцию и условия CC BY/CC BY-SA.
- Отсекать человеческое произношение названий, чужие виды, смешанные записи с неопределимой ведущей птицей, тишину и повреждённые файлы. Совпадение имени файла не гарантирует правильный звук.
- Предварительное прослушивание по решению пользователя необязательно; новые записи помечать `speciesHumanVerified=false`, а окончательную проверку оставлять пользователю.
- Не повышать счётчик покрытия, пока файл действительно не включён в офлайн-каталог, не проверен технически и не попал в собранный EXE.
- Резервная ветка перед продолжением: `backup/ptitsy-8.6-before-21-voices-20261104` (коммит `54b3364b10f0a3b6f21b4fcb065cce28444a1e6c`).

## Конкретные публичные источники-кандидаты

1. **Anser anser** — в категории Wikimedia Commons находятся четыре аудиофайла, в том числе `Anser anser - Greylag Goose XC436358.mp3` (40 с), `Anser anser - Greylag Goose XC518305.mp3` (11 с) и `Greylag Goose (Anser anser) - Bærum, Norway 2021-04-03.mp3` (11 с). Проверить лицензию конкретного файла через Commons API и звуковое содержание. Источник: https://commons.wikimedia.org/wiki/Category:Audio_files_of_Anser_anser
2. **Surnia ulula** — `Northern hawk owl.ogg`, 3,4 с, автор Jamescandless, CC BY-SA 3.0, описание «typical calls»; обязательна звуковая/техническая проверка до зачёта. Источник: https://commons.wikimedia.org/wiki/File:Northern_hawk_owl.ogg
3. **Ciconia nigra** — `Black stork.ogg`, 9,9 с, автор Jamescandless, CC BY-SA 3.0; **у файла отсутствует описание**, поэтому подтверждение видовой принадлежности слабее, чем по полевым метаданным. Требуется осторожная маркировка «не проверено». Источник: https://commons.wikimedia.org/wiki/File:Black_stork.ogg
4. **Ichthyaetus ichthyaetus** — `Larus ichthyaetus 720p.webm`, 65 с, автор Dmitry Mikhirev, CC BY-SA 4.0; описание прямо указывает на крики взрослых птиц и птенцов. Допустимо рассматривать *только выделенную реальную звуковую дорожку*, не видео как готовый MP3. Проверить отсутствие чужих голосов. Источник: https://commons.wikimedia.org/wiki/File:Larus_ichthyaetus_720p.webm

В текущем `scripts/commons_voices89.py` эти известные кандидаты уже перечислены как известные названия; не создавать вторую запись, если они уже включены в фактический каталог. Скрипты `tsa_voices89.py` и `attach_voices88.py` продолжают поиск оставшихся видов.

## Последующие проверки

В GitHub Actions использовать лицензированный Xeno-canto API v3 с существующим секретом `XENO_CANTO_API_KEY`, затем Wikimedia Commons и Tierstimmenarchiv с проверкой лицензионных данных конкретного файла. Для каждого из 21 вида сохранять статус `downloaded` / `rejected` / `not found`, URL, автора, лицензию, SHA-256 и признак пользовательской проверки. После пересборки сверить `coverage.json`, `missing-voices.csv`, оригинальные 265 хешей, Setup EXE, Portable EXE, настоящие снимки работающего Windows-приложения и QA-отчёт.

**Данное исследование не утверждает, что кандидаты уже скачаны или встроены в EXE.**

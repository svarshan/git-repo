# MoOLVa 7.6 — PRO MAX · «Чистый интерфейс»
Обновление существующего Electron-приложения в `svarshan/git-repo` после 7.5.0. Старые ветки и GitHub Releases 7.3–7.5 не перезаписываются.
## Левая панель 7.6
- На виду: Главная, Все птицы, Bird AI, Карта, Мой дневник, Полевой центр.
- Нативные раскрывающиеся группы: «Поиск и сравнение», «Библиотека и обучение».
- Служебные пункты «Экспедиция и полный архив», «Источники и лицензии» и переходы к аудиолаборатории/охране птиц доступны из «Настроек».
- Кнопка «Свернуть боковое меню» переводит десктопное меню в полосу значков, повторное нажатие раскрывает. Состояние меню и групп сохраняется отдельно в `ptitsy-nn.sidebar.v76`.
- Доступность: нативные details/summary для клавиатуры, чёткий фокус, подписи и сохранение маршрутов. На узком экране меню не превращается в негодную полосу.
## Каталог и надежность
- Голоса ULTRA 3.0: попытка пополнения до 298 видов с проверкой лицензий, источника, точного научного вида, техническим аудиоаудитом FFmpeg. Фактическое число может быть меньше 298. Нет синтезированных звуков.
- Энциклопедия COMPLETE: попытка найти только отсутствующие фотографии и полные статьи с открытыми лицензиями и подтверждением вида. Недостающие позиции честно помечены.
- Bird AI сохраняет настоящую модель Perch v2 и выбор 12/24 пятисекундных окон, результаты требуют ручного подтверждения.
- Поиск, карты OSM и обобщенные наблюдения GBIF, Птицы рядом, Академия, исходный дневник и экспорт остаются.
- Экспедиция 7.6: статистика и хронология только личных наблюдений из существующего дневника, без геокодирования мест и внешней синхронизации.
- Производительность: галерея фотографий и календарь рендерятся по требованию, а не оба на каждый переход.
- Архивы пользователя: прежние ключи `ptitsy-nn.journal.v1`, `ptitsy-nn.favorites.v1`, `ptitsy-nn.ui3.settings.v1` не изменены.
## Приёмка
GitHub Actions: проверки синтаксиса, JS/Python регрессии, реальный Windows ONNX inference, сборка Portable и Setup x64, SHA256 и отдельный неизменяемый GitHub Release. Ручные GUI/микрофон/аудио проверки на Windows остаются обязательными. Приложение не является надёжным индикатором реального присутствия птиц по карте.

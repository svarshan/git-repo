# MoOLVa 7.0 «Полевой атлас PRO» — состав Windows-сборки

Источник: прежнее приложение PtitsyNN на Electron, развитие оригинальной 5.0 и 6.3.1 без смены основы.

## Что изменено
- Версия 7.0, имена выпуска `MoOLVa-7.0-Setup-x64.exe` и `MoOLVa-7.0-Portable-x64.exe`.
- Настоящая офлайн-карта Нижегородской области: существующие проверенные географические зоны из GBIF, интерактивные точки, русские/латинские виды, изображения и переходы в паспорта. Новое: фильтр по зиме, весне, лету, осени, совместимый с фильтром месяцев, и возврат к полной карте.
- Bird AI с настоящей региональной Google Perch v2 ONNX-моделью: WAV/MP3/OGG/FLAC, последовательные пятисекундные окна 32 кГц (до 12; для файлов длиннее 10 мин — первые 10 мин), объединённые оценки, переход к паспорту и опубликованным наблюдениям вида на карте.
- Прямая запись с микрофона на 10/30/60 секунд: явный запуск и остановка, поток останавливается после записи, запись не передаётся в интернет. Для микрофона добавлена кратковременная доверенная модель разрешений, остальные запросы ограничены.
- Уведомления о случаях, когда реальная модель отсутствует, не смогла обработать запись, либо вид не найден. Нельзя выдавать относительную оценку за достоверную вероятность.
- Предрелизные статические регрессионные тесты; реальный smoke test модели в GitHub Actions.

## Что не следует преувеличивать
- Карта показывает ОБОБЩЁННЫЕ опубликованные наблюдения, а не гарантию наличия птицы во всех районах. Точки могут быть неполными.
- Модель Perch может не включать все 298 видов исходного регионального перечня. Это не научно подтверждённый самостоятельный мониторинг.
- Фоновая непрерывная обработка микрофона и автоматическая общая GPS-карта не заявлены.
- Не публикуйте точные координаты редких видов и гнёзд.
- Тесты CI не заменяют ручную проверку микрофона, размера экрана и загрузки модели на Windows компьютере.

## Обязательные условия выпуска
1. GitHub Actions завершает шаги построения медиакаталога, карты и SHA256-проверки модели Perch.
2. Пройден smoke-test настоящего ONNX inference.
3. В артефакте присутствуют оба Windows x64 EXE и SHA256SUMS.txt.
4. Перед выпуском создан отдельный архив исходников и сохранены старые 5.0, 6.0, 6.3.1.
5. Публикация в Releases с новым тегом `ptitsy-v7.0.0`, без перезаписи старых тегов.

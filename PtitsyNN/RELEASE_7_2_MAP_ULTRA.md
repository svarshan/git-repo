# MoOLVa 7.2 — Карта ULTRA

Это **обновление исходной Electron-энциклопедии**, а не отдельный веб-проект.

## Что реально входит
- Загружается региональный **OSM PBF по Нижегородской области** только во время сборки GitHub Actions. Локально пользовательский EXE ничего не скачивает.
- Из OSM извлекаются и упрощаются дороги (категории motorway/trunk/primary/secondary/tertiary/unclassified/residential), реки/каналы/ручьи, полигоны водоёмов и лесов, населённые пункты от городов до небольших деревень.
- Полигон области и оригинальные 26 точек остаются базовым слоем. Дополнительные подписи из OSM показываются с увеличением.
- Переключатели слоёв, свободное перемещение мышью, увеличение колёсиком, поиск города/деревни, сброс карты, сезонный фильтр, паспорт птицы.
- Точки GBIF показывают *укрупнённые исторические зоны наблюдений*. Дороги, леса, водоёмы и города **не** обозначают доказанные места присутствия конкретного вида.
- Bird AI Perch v2 и ранее собранная медиатека остаются в приложении.
- Выпускается Portable EXE и Setup EXE с новым именем \`MoOLVa-7.2-...\`, прежние Releases неизменны.

## Картографические данные и лицензии
- Источники PBF: \`https://geo2day.com/russia/volga_federal_district/nizhny_novgorod_oblast.pbf\`, резервный \`https://osmtoday.com/russia/volga_federal_district/nizhny_novgorod_oblast.pbf\`.
- Авторство: © OpenStreetMap contributors, [ODbL 1.0](https://www.openstreetmap.org/copyright).
- Генератор исходной ODbL-производной базы: \`scripts/make_ultra_map.py\`. Данные преобразуются и упрощаются только в данном скрипте; результат \`app/atlas-ultra-data.js\` включён в EXE. Для восстановления обработайте исходный региональный PBF тем же скриптом.
- Географическая точность зависит от OpenStreetMap. Для навигации или поиска точных гнёзд использовать нельзя.

## Зависимости сборки
GitHub Actions: Python 3.12 + requests + \`osmium==4.3.2\`. Загружаемый региональный PBF обычно ~75 МБ. Если источник недоступен, либо карта содержит менее 50 объектов любого из пяти основных типов, **сборка должна упасть**. Нет замены фиктивной картографией.

## Приёмка
1. В сборке присутствует OSM база с минимум 50 реальными объектами дорог, рек, озёр, лесов и населённых пунктов каждого типа.
2. Фильтры слоёв работают, подписи меняются с приближением, населённый пункт ищется по названию.
3. Кнопка «Где можно встретить птицу» и Bird AI работают независимо от слоя географии.
4. GitHub проверяет настоящую ONNX-модель, компиляцию интерфейса, сборку двух EXE и SHA-256.
5. GitHub создаёт уникальные архивные ветки перед сборкой и сохраняет Release 7.2 с обоими EXE. Архив 7.1 остаётся.

Ограничение: карты OSM неполные в местах, которые сообщество ещё не нанесло, это не полная навигационная карта с поворотами/адресами.

# Птицы Нижегородской области — MoOLVa Windows 5.0

Настоящее **настольное приложение для Windows 10/11 x64**, а не сайт в браузере.

## Состав
- Перечень из **298 подтверждённых в исходном опубликованном списке видов** с русскими и научными названиями.
- Поиск по названию, фильтрация по группам и по наличию материалов.
- Фотографии реальных птиц, скачиваемые для сборки с Wikimedia Commons при наличии разрешённой лицензии и идентификации вида.
- **Настоящие записи пения/криков птиц**, а не TTS-имитация, по свободным лицензиям; отдельно можно озвучить текст системным голосом Windows.
- Русские статьи из Википедии при наличии идентифицируемого соответствия, с указанием источника и лицензии CC BY-SA 4.0.
- Дневник наблюдений, резервная копия JSON, экспорт CSV для Excel, избранное, полностью офлайн после установки.
- Авторы/лицензии/ссылка для каждого добавленного фото и аудио.
- Нейтральная отметка об отсутствии данных: ни вымышленных птиц, ни анимации, ни синтетических природных голосов.

## Сборка EXE
1. На GitHub откройте **Actions → Птицы НН — Windows EXE → Run workflow**.
2. Workflow на Windows загружает свободно лицензированные медиа по Wikimedia API и статьи Русской Википедии, создаёт локальную базу с отчётом комплектности.
3. После проверки исходников и базы создаёт **инсталлятор Setup.exe** и **portable.exe** через electron-builder/NSIS.
4. Скачайте артефакт **Ptitsy-NN-5.0-Windows** (ZIP), распакуйте и запустите установщик. Интернет для использования готовой программы не нужен.

**Важно:** программа не утверждает, что для всех 298 видов уже найдены фото, записи или полные статьи. Точные числа отражены в приложении и в `coverage.json` в артефакте. Загрузка может зависеть от доступности Wikimedia во время GitHub Actions. Не подменяйте отсутствие файла анимацией или записью другого вида.

Исходный региональный перечень: https://www.oiseaux.net/en/oiseaux/russia/famille.nizhegorodskaya.oblast.html . Данные и лицензии медиа: https://commons.wikimedia.org/ . Тексты: https://ru.wikipedia.org/ .

## Локальная сборка
Установите Node.js 22+ и Python 3.11+:
```powershell
cd PtitsyNN
python -m pip install requests
python scripts/make_catalog.py
npm install
npm test
npm run build:win
```
Инсталляторы будут в `dist`. EXE не подписан кодовым сертификатом издателя, поэтому Windows может показать SmartScreen; отключать системную защиту не нужно.

Личный дневник хранится в профиле Electron Windows. При удалении приложения рекомендуется предварительно экспортировать JSON.

## Версия 2.2 — приоритет достоверности голосов птиц
- Звуки iNaturalist **не используются**: случайные наблюдения содержали разговоры и слишком тихую птицу.
- Приоритет: явно определённые по виду записи xeno-canto с разрешённой лицензией (при наличии личного API-ключа), затем категории аудиофайлов конкретного вида в Wikimedia Commons, затем поиск видовых записей Wikimedia.
- Автоматическое выравнивание громкости, высокочастотная фильтрация гула и ограничение длительности звучания выполняются перед упаковкой EXE.
- Если проверенной видовой записи не найдено — звуковая кнопка отключена. Не заменяем оригиналы синтетикой и случайным аудио.
- Все фото сохраняются вместе со сведениями об авторе, источнике и открытой лицензии.

## Version 2.4: world bird voice collection

Expanded licensed audio search to exact-species Wikimedia Commons audio categories, open field recordings from Russia and the British Library archived on Commons. Matches scientific binomials plus manually vetted taxonomic synonyms (e.g. Chloris chloris / Carduelis chloris). File-specific license, author and original source are mandatory. Mixed bird soundscapes, iNaturalist generic ambient audio and human speech are excluded by metadata checks. Recordings are normalized by the existing audio curator; unavailable licensed recordings remain explicitly missing instead of receiving a similar species' call. The optional xeno-canto API remains gated on XENO_CANTO_API_KEY in GitHub Secrets. See data/coverage.json for exact coverage after build.

Additional 2.4 source: Openverse (https://openverse.org/), restricted to individually licensed CC BY, CC BY-SA, CC0, or public-domain audio, with the exact scientific binomial in the sound's title. Only source links from Freesound, Wikimedia Commons and Internet Archive are permitted; other sound libraries must provide explicit offline redistribution permission. Openverse credits include creator, license, URL, and index information. All accepted audio is converted to normalized, offline-playable MP3 in curate_audio.py.


## MoOLVa 2.5 — «Голоса PRO»

- В каждой карточке встроен аудиоплеер: громкость, перемотка, повтор, замедление/ускорение с сохранением высоты тона.
- Отдельная вкладка «Сравнение голосов»: два выбранных вида, последовательное проигрывание без наложения.
- Пользователь может пометить запись как тихую, содержащую человеческую речь, шум либо ошибочный вид и выгрузить локальный JSON-отчёт. Никаких внешних отправок.
- Техническая экспертиза аудио в GitHub Actions на FFmpeg: проверка декодирования, громкости, тишины, одинаковых файлов для разных видов. Результаты: `data/audio-audit.csv`, `data/audio-audit.json`.
- Техническая проверка **не доказывает**, что на записи отсутствует человеческая речь или что птица определена правильно. Поле `audioHumanReviewed=0` отражает отсутствие индивидуального прослушивания человеком.
- Сохраняем предыдущую офлайн-базу реальных фотографий и статей, а для видов без допустимого звука не показываем подставной голос.


## MoOLVa 2.6 «Голоса MAX»
- Дополнительный поиск записей птиц по *точному* научному названию и проверенным таксономическим синонимам. При наличии секрета `XENO_CANTO_API_KEY` на GitHub Actions — API v3 xeno-canto (A/B/C, корректное родовое и видовое имя, проверка индивидуальной лицензии). Без секрета — альтернативный поиск точных видов на Wikimedia Commons. Никаких незадекларированных скачиваний с российских сайтов без разрешения.
- Для нового файла сохраняются лицензия, автор, источник, тип звука (песня, позывка, тревожный сигнал) и пометка «не проверено на слух человеком».
- «Аудиолаборатория»: весь перечень из 298 видов, сортировка, поиск, фильтры без записей/с записями/на ручную проверку, прослушивание, личная отметка «подходит» / «есть проблема», заметки, экспорт JSON.
- Личные оценки — только в `localStorage` текущего компьютера, без отправки в интернет. Они **не** являются коллективной научной верификацией вида.
- FFmpeg по-прежнему проверяет техническую целостность, громкость, тишину и дубликаты. Не утверждаем, что этот инструмент обнаруживает человеческую речь или правильность определения птицы.
- Общее число полученных офлайн-записей и количество недостающих видов определяется по `data/coverage.json` после сборки; никаких гарантированных 298 звуков.
- Запуск экрана и аудиоплеера не использует сетевые запросы. Старый дневник, избранное и доступные записи сохраняются.
- Для ключа: GitHub → Settings → Secrets and variables → Actions → New repository secret → Name: `XENO_CANTO_API_KEY`, Value: собственный ключ аккаунта xeno-canto (не публиковать его в коде/чате). Из-за условий конкретных лицензий NC/ND не используются.


## MoOLVa 2.7 «Голоса ULTRA» (Windows)
- Добавляются **до двух дополнительных лицензированных записей на один вид** (при наличии в международных библиотеках), независимо от основного файла. Дорожки имеют собственные автора, лицензию, тип звука, подтверждение соответствия латинскому названию и FFmpeg-контроль. Качество самого определения вида человеком не заявляется.
- **Живая спектрограмма**: анализ реального спектра Web Audio FFT во время воспроизведения; не статичная декоративная иллюстрация. Нижняя/верхняя часть — низкие/высокие частоты до ~9 кГц. 
- **Свои записи** WAV, MP3 или OGG: импорт в локальный IndexedDB приложения, ограничение 12 МБ/запись, до четырёх личных записей на один вид, проверка заголовков файлов, возможность удаления. Личные файлы **не** являются научно проверенными и не попадают в общий EXE или на внешние серверы.
- Переключатель основных, дополнительных и личных дорожек в каждой карточке, включая виды без официально найденного голоса. Предыдущий аудиоплеер (громкость, повторы, скорость и перемотка) и функция сравнения двух птиц сохранены.
- Звуковая база и личные записи **не смешиваются**: дополнительные распространяемые дорожки скачиваются исключительно с подтверждённой свободной лицензией конкретной записи, личные — только из выбранного пользователем файла.
- После сборки в `data/coverage.json` публикуются `birdCalls`, `extraAudioTracks`, `audioTracksTotal`, `multiTrackSpecies`. Это количественные показатели, а не гарантия правильности видов на слух.
- Если ключ API xeno-canto в GitHub Secrets не установлен, поиск по этой API недоступен; программа использует Wikimedia Commons и уже проверенную ранее подборку, не выдавая отсутствие ключа за сбой.
- Сборка Windows 10/11 x64 выдаёт **Setup.exe и Portable.exe**. Проверяйте оба файла, не скачивайте незавершённый ZIP, готовые файлы следует доставлять по отдельности.

- Итог: проверка тестов GitHub Actions, создание установочного и Portable EXE Windows 10/11 x64. Файлы следует доставлять пользователю отдельно.


## MoOLVa 3.0 — «Полевой помощник» · интерфейс по референсу (24.10.2026)

- Тёмная стартовая панель по предоставленному макету: логотип, левое меню с иконками, верхний быстрый поиск, художественная встроенная панорама Нижнего Новгорода, 4 динамических показателя комплектности и 5 быстрых плиток разделов.
- Осенняя подборка показывает реальные фотографии видов из лицензированного офлайн-каталога. Это примеры для знакомства, **не** неподтверждённый прогноз присутствия птиц сегодня.
- Новая фотогалерея с поиском по русскому и научному названию. Вся медиатека работает без сети; отсутствие фотографий не заполняется выдуманными иллюстрациями.
- Карта встреч в текущем формате показывает агрегированные **места из личного дневника**. Существующие записи содержат текст места, но не геокоординаты: на геокарту не ставятся вымышленные точки. Реальная картография с привязкой к координатам — отдельная будущая функция.
- Календарь птиц отображает реальные наблюдения по месяцам за всё время без фиктивного расписания миграций. Настройки яркости, плотности интерфейса и анимаций сохраняются локально.
- Существующие вкладки: каталог, полевой определитель, избранное, сравнение голосов, аудиолаборатория, дневник, статьи и источники — сохранены. Старые ключи localStorage и IndexedDB не переименованы.
- Windows 10/11 x64: отдельный установочный NSIS EXE и Portable EXE. Новая сборка GitHub Actions: `Ptitsy-NN-5.0-Windows`.
- Доступные данные в комплекте зависят от аудита `data/coverage.json`. Программа не утверждает, что все записи прослушаны специалистом.

Сохраните резервную копию дневника (JSON) перед крупным обновлением. Для обновления ранее установленной версии запустите новый Setup EXE, Portable EXE запускается без обычной установки. Отсутствие подписи издателя может привести к предупреждению SmartScreen — не отключайте защиту Windows.

## MoOLVa 4.0 «Живая природа» — новый региональный атлас
Дата: 24.10.2026.

### Карта вероятных встреч
- Региональная карта **именно Нижегородской области**, подложка: M.Bitton, Wikimedia Commons, [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) — [оригинал](https://commons.wikimedia.org/wiki/File:Nizhny_Novgorod_Oblast_(location_map).svg). Проекция и границы: север 58.19°, юг 54.35°, запад 41.60°, восток 47.96°. Карта загружается **во время CI-сборки**, а не при использовании программы.
- Источник обозначений: открытая поисковая выборка [GBIF Occurrence API](https://techdocs.gbif.org/en/openapi/v1/occurrence), **не полный научный ареал**. Отбираются только птицы каталога, с достаточно свежими координатными записями и привязкой к Нижегородской области. Данные группируются в ячейки около 30 км с требованием не менее 3 записей и наблюдений в разные даты. Оригинальные координаты, имена наблюдателей, прямые записи и гнёзда не распространяются.
- Наведение курсора, фокус клавиатуры или клик на ячейке показывают список видов, число использованных сообщений о наблюдениях и диапазон лет. Выбор вида фильтрует зону карты. У видов без данных карта честно пуста: это не доказательство отсутствия птицы.
- **Карта личного дневника исключена** по желанию пользователя, данные журнала при этом сохранены.
- Если при сборке GBIF недоступен, программа не рисует вымышленные метки. Источник, дату выборки и число проверенных записей видно под картой.
- Это иллюстрация **мест, где потенциально можно встретить птицу** на основании публикаций; не точный прогноз на сегодняшний день, не маршрут к гнезду, не карта плотности популяции.

### Дополнительные офлайн-разделы
- «Орнитологический помощник»: подбор карточек по словам в существующих описаниях, без выдумывания признаков или AI-распознавания.
- «Сравнить по фото»: загрузка личного изображения на своём компьютере, ручное сопоставление с лицензированным примером вида.
- «Сравнить голоса»: локальная звуковая запись, реальная осциллограмма и отдельный оригинальный звук вида.
- «Академия»: интерактивные вопросы с реальными фото птиц; личные баллы сохраняются локально.
- «Красная книга»: проверенные ссылки на нормативные и природоохранные источники, без автоматического присвоения непроверенного статуса.
- «Экспедиция»: локальный экспорт дневника JSON с сохранением совместимости с 2.x/3.x.

**Ограничения:** эта версия не содержит научно аттестованной AI-модели автоматического распознавания по фото или голосу; не обещает функции, которые не реализованы. Android-приложение и полноценная синхронизация между платформами пока не выпущены. По запросу пункты 3, 4 и 5 концепции (карта личных встреч, панель изменений природы и автономная станция записи) не реализуются.

## MoOLVa 6.0 — «Большой атлас природы» · 24 октября 2026

Новая версия развивается на базе 4.0 без сброса пользовательских данных и без возвращения ранее исключённых модулей: карты личных встреч, «Пульса природы» или фоновой орнитологической станции.

### Реализовано в 5.0

- **Укрупнённый орнитологический атлас** Нижегородской области. Географическая подложка с еquirectangular-проекцией (M.Bitton, Wikimedia Commons, CC BY-SA 4.0, [первоисточник](https://commons.wikimedia.org/wiki/File:Nizhny_Novgorod_Oblast_(location_map).svg)); координаты и границы проверяются по указанным на странице изображения. Не является офлайн-заменой маршрутизатора или карты дорог.
- **Сезонный слой наблюдений** по месяцам. Указаны только те месяцы, для которых найдены не менее трёх открытых сообщений о встречах в обобщённой ~30-километровой ячейке не менее чем за две различные даты. Если месяца нет, приложение не утверждает отсутствие птицы.
- **Точки карты с фотографиями**, русским названием и научными данными о числе и диапазоне лет наблюдений. Все фото из уже проверенного локального каталога.
- **Фильтр по конкретному виду** и месяцу, приближение карты, указание происхождения сведений, экспорт только агрегированной таблицы для Excel в CSV. Личные координаты, записи наблюдателей и точные гнёзда не экспортируются.
- **Академия по голосам** — вопросы на базе настоящих лицензированных локальных записей, сохранение числа правильных ответов; прежняя фото-викторина сохранена.
- **Полный локальный архив данных** — дневник, избранное, настройки и результаты обучения. Режим восстановления проверяет типы, ссылки на виды и ограничения полей и предлагает явное подтверждение. Всегда храните резервный архив приватно: в нём могут находиться личные места и заметки.
- **Проверки релиза**: тесты регрессий, безопасности фильтрации, наличия географических данных, месячных отметок, сборки Windows и сохранности старых функций.

### Данные, качество и ограничения

Исторические биологические наблюдения получены через [GBIF Occurrence Search API](https://techdocs.gbif.org/en/openapi/v1/occurrence). При сборке используется ограниченная по запросам выборка с фильтрами по типу лицензии, региону, координатной точности, дате и раскрытию чувствительных сведений. Количество опубликованных записей **не равно** плотности популяции. Показанные обобщённые ячейки — районы, в которых *фиксировались наблюдения*, но не полный ареал, не прогноз встретить вид и не точные координаты птицы.

В 5.0 **нет** притворного автоматического AI-распознавания птиц: ручное сравнение фото и голосов сохраняется, пока не появится локальная модель с подтверждёнными точностью, лицензией и ресурсными требованиями. Нет обещаний полной базы голосов всех видов, сторонней Android-программы или автоподписанных обновлений. Все картинки и звуки публикуются только при наличии разрешённых лицензий и источников.

### Windows

Сборка GitHub Actions `Ptitsy-NN-5.0-Windows` содержит два отдельных файла: `MoOLVa-6.0-Setup-x64.exe` и `MoOLVa-6.0-Portable-x64.exe`. Установщик не подписан сертификатом издателя. Прежде чем заменять прошлую установку, сохраните архив дневника.

## MoOLVa 6.0 — «Живая энциклопедия»: интегрированный выпуск

*Выпуск содержит работы этапов 5.1, 5.2, 5.3 и 5.4 с достоверными ограничениями.*

- **Атлас PRO MAX (5.1):** сохраняются достоверные укрупнённые зоны наблюдений и сезонный выбор. Hover-карточки показывают действительные записи GBIF; карта не содержит пользовательские отметки и не публикует координаты гнёзд. Полного покрытия всех 298 видов пока нет.
- **Голоса ULTRA (5.2):** при сборке выполняется дополнительный ограниченный по времени поиск научно идентифицированных CC-лицензированных звуков на Commons/xeno-canto, повторная проверка технического качества и источников; неподтверждённые материалы не подставляются. Количество доступных записей выводится по реальной базе, а не по цели.
- **Энциклопедия MAX (5.3):** паспорт каждого вида показывает фактическую доступность фотографий и записей, месяцы и районы GBIF и короткие разделы о внешнем виде, питании, местообитании и размножении, если соответствующие сведения найдены в существующем лицензированном тексте. Отсутствующие сведения не выдумываются. Дополнительно — сравнение двух видов рядом с настоящими медиа.
- **Bird AI (5.4):** локальная предобученная модель Perch v2, восточно-европейский ONNX-вариант от Google Research / justinchuby / tphakala, Apache-2.0. Windows-комплект собирает модель и labels с проверкой SHA256, включает native onnxruntime-node и тестирует реальный CPU-прогон с 5 сек аудиосигнала. Загруженный пользователем файл обрабатывается только локально. Это вероятностная модель, нуждается в полевой верификации, особенно для редких и нескольких одновременно поющих видов. Она не распознаёт птицу по фото; в фото-разделе остаётся честное ручное сравнение.
- **Стабильность:** изолированная предзагрузка Electron, закрытый IPC, проверка размеров и чисел PCM до ONNX-вызова, отсутствие удалённого API в пользовательском приложении, тестовые релизные ворота, безопасный архив личного дневника.

### Ограничения достоверности
Оценка модели в Bird AI — относительная оценка среди классов конкретной модели, не откалиброванная вероятность. Для автоматического подтверждения видов или охранных выводов требуется экспертная проверка. Лицензии, авторов и тексты подтверждений следует сохранять вместе с переносимыми материалами. Коммерческий выпуск зависит от лицензии каждого стороннего медиафайла (в том числе отличающейся от лицензии модели).

### Географическая подложка, версия 6.0

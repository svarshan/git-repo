# MoOLVa 7.7 PRO MAX · Умная природа ULTRA

Обновление существующего репозитория `svarshan/git-repo/PtitsyNN`. Релизы 7.3, 7.4, 7.5 и 7.6 сохраняются без перезаписи.

## Подтверждённые возможности по коду
1. Bird AI 4.0: реальная прежняя модель Google Perch v2 (ONNX) с 12/24 окнами, выделением топ‑3 модельных ответов, экспериментальным переключаемым полосовым фильтром 160–9000 Гц и локальной историей из 25 результатов (без хранения исходного аудио). Модельные оценки — не вероятности, шумоподавление не гарантирует рост точности.
2. Голоса ULTRA 4.0: существующий цикл 298 реальных лицензированных звуков с аудиоаудитом. **298 — целевой максимум, не обещание.** Для отсутствующих голосов в карточке честно показан дефицит.
3. Энциклопедия: поиск недостающих статей и фото в проверенных открытых источниках без выдуманных данных.
4. Карта ULTRA 4.0: фильтр по существующим таксономическим группам каталога, однонажатийные сезоны, тот же GBIF с укрупнёнными пространственными ячейками и датами, OSM офлайн. Не прогноз присутствия в реальном времени.
5. Интерфейс Premium 3.0: закрепление до семи разделов, ширина боковой панели 235–340 пикс., сохранение свернутой панели и двух групп 7.6.
6. Ctrl+K: глобальный локальный поиск птиц по имени, латинскому названию, группе и фрагменту реальной статьи, плюс поиск разделов приложения.
7. Дневник 4.0: неразрушающие названия экспедиций (отдельный localStorage), настоящие личные фото (JPEG/PNG/WebP до 3 МБ) и аудио (MP3/WAV/OGG/WEBM/MP4 до 5 МБ) в IndexedDB, локальный экспорт/импорт JSON вложений с ограничением 45 МБ; старый JSON дневника версии 1 остается независимым. При восстановлении архивов порядок: импорт старого дневника, затем архив экспедиций 7.7.
8. Сравнение видов PRO продолжает показывать две реальные фотографии, доступные голоса, исходные статьи, группы и укрупнённые географические сведения (не синтезирует неуказанные размеры).
9. Производительность: галерея и календарь остаются ленивыми от 7.6; новый поиск не требует сети; хранение вложений отдельно от исходных записей.
10. Надёжность: Node.js регрессия, Python аудиотесты, контроль реальной ONNX-инференции на Windows, сборка Setup и Portable, проверка SHA256, неизменяемый GitHub Release.

## Ограничения и приёмка
Не выдавать неполный медиакаталог за полный. Автоматические тесты не заменяют ручную проверку GUI, воспроизведения, микрофона, файловых диалогов и обновления на реальном Windows 10/11. Старые ключи `ptitsy-nn.journal.v1`, `ptitsy-nn.ui3.settings.v1` не изменяются.

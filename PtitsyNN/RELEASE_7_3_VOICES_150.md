# MoOLVa 7.3 «Голоса ULTRA MAX» — первая цель: 150 видов

**Состояние исходной 7.2 по отчёту GitHub Actions:** 298 видов птиц; 78 видов с основной записью голоса; 2 дополнительных аудиотрека. Это не 150 видов.

## Реально внедрённая работа
- Сохраняются все прежние проверенные записи, фотографии, статьи, карта ULTRA и Google Perch v2.
- На **каждой** GitHub-сборке, в том числе после восстановления кэша, выполняется дополнительный поиск звуков для видов, у которых нет голоса.
- Источники: Wikimedia Commons, Openverse и Xeno-canto при настроенном владельцем секрете `XENO_CANTO_API_KEY`; новый поиск оригинальных звуков из подтверждённых наблюдений iNaturalist.
- iNaturalist: совпадение полного латинского имени вида, класс исследования `research`, отдельная лицензия звука **CC0, CC BY или CC BY-SA**, автор и ссылка на исходную запись. Не использовать наблюдательскую лицензию вместо звуковой; CC BY-NC и другие ограниченные лицензии не включать.
- Никаких синтезированных голосов; недоступные записи помечаются как отсутствующие.
- Из новых аудиофайлов FFmpeg создаёт пригодные к офлайн-воспроизведению MP3, затем проходит анализ длительности, громкости, тишины, декодирования и точного хэша для исключения дубликатов.
- Дополнительные виды учитываются в `coverage.json` в `milestone150`: `baseline`, `target`, `verifiedAudioSpecies`, `achieved`, `shortfall`, источники и количество отвергнутых кандидатов. Итог пересчитывается **после** технического аудита.
- Проверка вида **по записи на слух экспертом не выполнялась**; метаданные исследовательского наблюдения не равно гарантия правильной биологической идентификации.

## Граница готовности цели
150 видов — **цель, не заранее обещанный факт**. Сборка не должна заявлять, что достигла 150 видов, если отчёт показывает меньше. Новая версия может быть опубликована с честно указанным промежуточным охватом. Чтобы пополнять архив далее, нужен новый выпуск с собственным номером версии — прежние GitHub Releases не перезаписываются.

## Автоматизация и резервные копии
Рабочие ветки GitHub `archive/ptitsy-7.2-before-voices-20261024` и `archive/ptitsy-7.3-source-20261024`, отдельная версия исполняемого файла с именем `MoOLVa-7.3-Portable-x64.exe` / `MoOLVa-7.3-Setup-x64.exe`. Загружаемые исходные звуковые файлы сохраняются в медиа-кэше успешной Actions-сборки.

Автор и лицензия указываются для каждой записи; права могут зависеть от конкретного пользователя. Дополнительный источник: https://www.inaturalist.org/pages/search+urls и https://help.inaturalist.org/en/support/solutions/articles/151000169918-can-i-use-the-photos-and-sounds-that-are-posted-on-inaturalist-

**Нужный ключ:** Xeno-canto v3 требует собственный API-ключ. Он не встроен в код, а берётся из секрета `XENO_CANTO_API_KEY` при наличии.

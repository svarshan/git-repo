# MoOLVa 7.4 — «Голоса и Bird AI PRO»

## Что изменено
- Развивает существующую MoOLVa 7.3 на Electron, сохраняет 7.2 карту ULTRA, фотокаталог, дневник, Академию, Perch v2 и архивы.
- Новый **настоящий офлайн-спектрограф** звука: FFT из браузерного AudioContext, отображение частот 200–13 000 Гц, до 45 секунд сигнала. Нажатие на диаграмму перематывает реальный файл; длинный сигнал не изображается фиктивно.
- Для каждого класса птицы, найденного реальной Google Perch v2 в пятисекундных окнах, показывается отметка времени, которую можно нажать и прослушать отдельные пять секунд.
- Модель **не** возвращает достоверность наличия вида. Оценки относительны для классов региональной нейросети, а прогнозы требуют подтверждения.
- Цель аудиотеки: **200 / 298** видов. Новая программа `scripts/voices_200.py` сохраняет старые лицензированные звуки и пытается получить только отсутствующие: через Commons, Openverse, опционально Xeno-canto v3 с секретом владельца и реальные индивидуальные записи iNaturalist с лицензией CC0, CC BY или CC BY-SA.
- Каждому звуку нужны источник, автор, точный ID записи, совпадение латинского вида, лицензия именно звука, FFmpeg-декодирование и технический аудиоаудит. Человеческое прослушивание не заявлено.
- Число **200 — цель**, а не обещание. `data/coverage.json` включает `milestone200` с фактическими `verifiedAudioSpecies`, `achieved`, `shortfall` после аудита. Старый `milestone150` сохраняется и пересчитывается.
- Все голоса и карта доступны офлайн после установки без запросов в интернет. Обновление каталога производится во время GitHub Actions.
- Сохраняются исходники 7.3 в отдельном GitHub-архиве до обновления. Версия 7.4 получает собственные имена `MoOLVa-7.4-Portable-x64.exe`, `MoOLVa-7.4-Setup-x64.exe`, неизменяемый GitHub Release `ptitsy-v7.4.0` и SHA256.

## Проверка готовности
- npm test проверяет код спектрограммы, привязку Perch к пятисекундным фрагментам, лицензионные метаданные новых записей, географию карты и существующие 298 видов.
- Python unittest проверяет сопоставление научных названий и условия лицензий.
- GitHub Windows CI проверяет настоящий локальный ONNX-инференс и создаёт Portable + Setup EXE с контрольными суммами.
- Приложение не считается полностью протестированным на ПК до ручной проверки микрофона, аудиоплеера и графики на Windows.

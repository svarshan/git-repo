# MoOLVa «Птицы Нижегородской области» — 8.3 PRO MAX

## Защита исходного релиза
Неподвижная исходная точка разработки — успешная 8.2, коммит \`4fe2cccaac3ce543175bb01e54abbc2d88966620\`. Резервная ветка: \`archive/ptitsy-8.2-verified-before-8.3-20261101\`. Стабильный \`master\` не переписывается до завершения проверки.

## 12 направлений версии 8.3
1. **Голоса** — дополнительные строго видовые запросы на Wikimedia Commons, отдельно только лицензированные реальные записи; их наличие не гарантируется.
2. **Аудио QA** — техническая оценка, очередь прослушивания, SHA-256 сопоставление файлов разных видов и проверка подозрительных названий источников. Автоматический код **не умеет** удостоверять отсутствие человеческой речи.
3. **Фотографии** — контроль реальных фото по декодированию, разрешению, правам и метаданным; монтажные листы из 298 реальных файлов для визуальной проверки.
4. **Медиапаспорт** — авторы, первоисточники, лицензии, пользовательское подтверждение / пометка сомнительного и выгрузка отчёта по каждому виду.
5. **Bird AI** — настоящая локальная модель Perch v2 и дополнительные необязательные профили фильтра низкочастотного ветра и высокочастотного шипения. Точность этих фильтров не доказана, поэтому они выключены по умолчанию.
6. **Сравнение** — реальные снимки и аудиозаписи двух видов, опубликованное описание плюс авторство исходников. Никаких придуманных отличий.
7. **Карта PRO** — выбор места, радиуса и сезона только из укрупнённых опубликованных зон. Не прогноз присутствия и не координаты гнёзд.
8. **Поиск** — русский, латинский, транслитерация, опубликованные описания, фильтры по доступности материалов.
9. **Компактный интерфейс** — второстепенный «Полевой центр» перемещён в сворачиваемую группу; все существующие вкладки остаются доступными.
10. **Резервные копии MAX** — локальные атомарные SHA-256 копии, ротация, список с проверкой целостности, открытие папки, включение ручных отметок и версии приложения. Импорт полного JSON-архива и откат ошибочного импорта сохранены.
11. **Обновление** — обе отдельные сборки Setup/Portable x64 с прежним appId, кнопка подготовки SHA-256 копии перед запуском установщика; автоматического удалённого обновления пока нет и оно не заявляется.
12. **Выпускной контроль** — 298 видов/фото/статей, регрессия 261 проверенного аудиофайла 7.9, реальные семь Windows-скриншотов, тесты Node/Python, оба EXE, SHA256SUMS и сохранённые QA приложения.

## Не выдавать за выполненное
- Недостающие голоса: точное число определяет **только** новая собранная версия и её \`coverage.json\`; цель 298/298 ещё не достигнута.
- Визуальная правильность всех фотографий и отсутствие человеческого голоса требуют индивидуального просмотра/прослушивания. Число отметок «проверено вручную» при первом запуске равно нулю.
- Модель Bird AI не калибрует вероятность распознавания и может ошибаться.
- Установщик нельзя считать проверенным на личном ПК только по результатам Windows GitHub Actions.

## Откат и перенос
Откройте «Контроль фото и голосов» → «Сделать резервную копию» / «Проверить SHA-256 архивов» / «Папка с копиями». Для переноса между ПК используйте **Экспорт полного архива** в разделе резервных копий и восстановление проверенного JSON на втором компьютере. Перед запуском нового Setup нажмите «Сохранить перед обновлением». Не удаляйте папку данных пользователя и не удаляйте предыдущие резервные ветки или GitHub Releases.

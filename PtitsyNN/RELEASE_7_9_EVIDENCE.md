# MoOLVa 7.9 — проверяемый выпуск Windows EXE

Начиная с 7.9 публикуются дополнительные обязательные артефакты: 6 PNG скриншотов настоящего работающего упакованного Windows Electron приложения, test-report.md/test-report.json с результатами автоматических проверок и missing-voices.csv/missing-voices.md со списком отсутствующих голосов.

Скриншоты создаёт упакованный EXE в Windows GitHub Actions посредством Chromium webContents.capturePage (offscreen). Это не графические макеты и не изображения, созданные генератором. Размер и SHA256 каждого PNG перепроверяются до публикации; при сбое выпуск не создаётся.

Отчёт фиксирует результаты Node.js и Python, нативной модели Perch v2 и факт успешной упаковки обоих EXE. Эти автоматические проверки не подменяют ручную проверку пользовательского монитора, микрофона и больших личных архивов.

Перечень безголосых видов берётся исключительно из фактического offline-каталога той же сборки и сверяется с coverage.json. Синтетических птичьих звуков нет. Целевой охват 298 видов не выдаётся за достигнутый.

Сохранены предыдущие релизы и совместимость пользовательских записей 7.8.

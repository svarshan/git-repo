# MoOLVa 8.1 PRO MAX — «Интеллект природы» (Windows x64)

Версия 8.1 сохраняет все разделы и форматы MoOLVa 8.0.0. Нет принудительного удаления дневника, голосов и фотографий, сохранения и прошлые релизы остаются доступны.

## Двенадцать направлений

1. Bird Vision AI 2.0 — реальный MIT EfficientNet 525-class ONNX со сверкой SHA-256, три независимых сохранённых по пропорциям фрагмента исходного кадра через CPU, усреднение логитов, обязательный e2e-тест на настоящем PNG в Windows EXE. Никаких вымышленных вероятностей; точность на 298 видах Нижегородской области не утверждается.
2. Bird Compare — два разных реальных региональных паспорта с лицензированными фотографиями, голосами, исходными выдержками статьи, источником и переходом к паспорту. Не приписываются придуманные морфологические признаки.
3. Bird Sound AI 8.0 — реальные временные окна Perch v2 и прослушивание исходного участка в разделе Bird AI; проверка тихих и искажённых записей; пользователь видит, какому кандидату принадлежит фрагмент.
4. Voices COMPLETE 4.0 — приоритетное восстановление доказанных голосов из 7.9 и расширение только разрешёнными таксономически сопоставленными записями. Сравнение точного списка латинских названий с неизменяемым 7.9; запрет публикации при потере хоть одного вида или падении ниже 261 основных записей.
5. Nature Atlas 8.0 — исторические укрупнённые наблюдения, фильтр по виду, сезону, минимальному числу сообщений, последний год в выбранной выборке. Среда обитания не придумывается, точные гнёзда не раскрываются.
6. Bird Passport 7.0 — реальные видовые карточки с полноэкранными снимками, атрибуцией, голосами, выдержками статей и сравнениями в одном рабочем потоке.
7. Field Assistant 3.0 — четыре крупные кнопки фото, голос, карта, дневник внутри прежнего единого интеллектуального центра.
8. Академия птиц 5.0 — фото и аудио по уровням, фиксация ошибок и повтор видов, которые пользователь путает. Старые сохранения Академии остаются совместимыми.
9. Экспедиция PRO — хронологический отчёт наблюдений, фильтр дат, выгрузка самодостаточного оформленного HTML для печати/PDF, безопасное экранирование текста. При отсутствии точных координат расстояние и карта маршрута не выдумываются.
10. Backup Safe 3.0 — SHA-256 новых архивов, приём и проверка старых архивов, отклонение испорченных файлов, проверка дубликатов, атомарная транзакция восстановления IndexedDB-вложений и попытка отката основных настроек при сбое. Совершенно атомарной операции сразу на localStorage и IndexedDB не существует: храните исходный JSON отдельно.
11. Performance ULTRA — сохраняется ленивая галерея и отложенные медиа; замер браузерного DOMContentLoaded и доступной JS-памяти на компьютере, а не обещание скорости без бенчмарка.
12. Windows Release Quality MAX — Node и Python QA, нативные Perch и Bird Vision e2e тесты, семь PNG реального EXE, GUI-нажатия сравнения и фильтра карты, тест восстановления/порчи архива, аудио-регресс-блокер, отчёты, проверка SHA256 EXE и неизменяемая архивная ветка.

## Известные ограничения

- Модель фотографии обучена на внешнем наборе из 525 видов. Её реальная независимая точность для каждого из 298 видов Нижегородской области пока не измерена.
- Распознавание голоса выдаёт относительные оценки и требует ручной проверки. Техническая проверка аудиофайла не равна прослушиванию экспертом.
- Автоматические скриншоты и GUI smoke на Windows GitHub Actions не заменяют испытание настоящих микрофона, динамиков и больших личных архивов на пользовательском ПК.
- В новом отчёте голосов должны быть 261+ лицензированных вида без потери ни одного из ранее проверенных. Если источник невозможен, релиз запрещён, а не дополнен поддельным звуком.

# MoOLVa Кино 1.0 — предварительный проект для Android TV / Google TV

Русский интерфейс с навигацией пультом, каталог TMDB (нужен личный ключ API v3), подключение Jellyfin по логину, поиск, избранное, локальная история, ExoPlayer и экспорт/импорт истории и избранного в JSON.

## Перед просмотром

1. Нужен свой сервер Jellyfin с видео. Телевизор и сервер должны видеть друг друга по сети. Пример адреса домашнего сервера: `http://192.168.1.10:8096`.
2. В «Настройках» введите адрес, имя и пароль Jellyfin и нажмите «Подключиться». HTTP используйте только в домашней сети: он не шифрует пароль. Для доступа из интернета используйте HTTPS.
3. Пароль сохраняется не как пароль, однако токен Jellyfin и ключ TMDB хранятся локально в настройках Android. Автоматическое резервирование Android для приложения отключено. Резервную копию используйте только на доверенном устройстве.
4. Для каталога зарегистрируйте собственный API-ключ TMDB v3 и введите его в настройках. Каталог TMDB содержит сведения, а не видео. Воспроизведение возможно из личной медиатеки Jellyfin.
5. Сохранять и выбирать копии можно при наличии на телевизоре совместимого системного приложения для выбора файлов. JSON содержит избранное и историю, но не данные входа и ключи. Восстановление заменяет текущие избранное и историю. Для дополнительной копии сохраняйте файл на внешний носитель.

## Сборка

В Android Studio откройте папку проекта и дождитесь установки необходимых Android SDK 35, Gradle 8.9 и JDK 17. Запустите сборку debug APK. Для GitHub Actions перенесите проект в отдельный репозиторий вместе с `.github/workflows/android.yml` и запустите workflow; APK появится в артефактах успешного запуска. Для установки на телевизор перенесите APK через USB или другой доверенный способ и разрешите установку из выбранного источника в настройках Google TV.

Debug-сборка предназначена для проверки. При смене ключа подписи Android не позволит обновить приложение поверх существующей установки. Чтобы не потерять данные, предварительно экспортируйте резервную копию. Настоящая постоянная подпись release здесь не настроена.

## Ограничения предварительной версии

- Приложение требует интернет для TMDB и доступ к серверу для Jellyfin. Не хранит фильмы и не включает контент.
- Прямой поток Jellyfin (`Static=true`): серверное перекодирование, управление профилями воспроизведения и синхронизация позиции с Jellyfin не реализованы. Форматы, которые не поддерживаются устройством, могут не воспроизводиться.
- Подбор дорожек и субтитров зависит от того, что ExoPlayer обнаружит в потоке; внешние субтитры и DRM отдельно не реализованы.
- Показывается до 100 элементов раздела; автоматической постраничной подгрузки нет. Автоматический переход между сериями не реализован.
- Избранное и история сохраняются на телевизоре. Системный выбор файла на некоторых TV может отсутствовать.
- Нужно отдельно проверить работу в эмуляторе и на TCL 55C6K. Нельзя гарантировать работоспособность APK до успешной сборки и тестирования.

## Версия 1.2: локальный TorrServe

Установите TorrServe на телевизор из официального репозитория YouROK/TorrServe. При первом запуске загрузите сервер в «Обновления» → «Обновить сервер из сети», выберите локальный сервер и запустите его. Подключение MoOLVa происходит только к `http://127.0.0.1:8090` на самом телевизоре. Если выбранный локальный сервер использует другой порт или требует HTTP-авторизацию, эта версия к нему не подключится. Настройте локальный доступ без авторизации только в доверенной среде, не открывайте сервер в интернет. Компьютер для такого варианта не нужен.

В разделе «Торренты» доступен ввод magnet-ссылки или прямой ссылки на .torrent, выбор видеофайла, просмотр добавленных раздач и поиск через предварительно настроенный и включённый Torznab в TorrServer. Сам поисковый источник не входит в приложение; доступность, результаты, законность распространения и качество источников не гарантируются. Torrent-сеть раскрывает IP-адрес другим участникам. На экране карточки TMDB поиск запускается по названию; совпадение необходимо проверять самостоятельно. Плеер использует прямой поток, поддержка кодеков и внешних субтитров не гарантируется.

Сборка личного APK выполняется через секрет TMDB_API_KEY; чтобы не публиковать встроенный ключ в открытом артефакте, APK упакован в архив 7z. Пароль архива — этот API Key v3. Секрет всё же может быть извлечён из самого распакованного APK. Проверять на TCL 55C6K отдельно; сборка и тесты не являются подтверждением работы на конкретном телевизоре.

## Версия 1.3: поиск через TorAPI

В поиске источников доступен экспериментальный неофициальный сторонний сервис TorAPI (`https://torapi.vercel.app`): RuTracker, RuTor, Kinozal, NoNameClub. При выборе кнопки поиска название и IP-адрес получает оператор TorAPI. Запросы к этому сервису не содержат ключ TMDB или учетные данные Jellyfin. Сервис и источники могут быть недоступны, выдавать ошибки, устаревшие данные или нерелевантные результаты. Пользователь самостоятельно проверяет законность использования. При выборе раздачи приложение получает magnet и обращается к локальному TorrServer; для получения видео нужны доступные раздающие и поддерживаемый формат. Использование торрентов раскрывает IP-адрес другим участникам. Источники не гарантируют и не проверяют права на контент.

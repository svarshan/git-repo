# Инвентаризация · Маяк 2.0

Сборка офлайн Windows 10/11 WPF .NET 8. Исходники в `Inventarizatsiya/source.zip`.

Изменения: тёмно-синий стиль «Маяк», янтарные акценты, фото маяка на главной панели, две кнопки Excel (пустой бланк 200 строк и заполненный пример 768 товаров). Кнопка «Вся база — Excel» сохраняет реальные текущие остатки пользовательской базы.

Встроенные xlsx копируются из ресурсов одного EXE; без скачивания шаблонов и без интернета. GitHub Actions выполняет два WPF smoke-теста, которые также экспортируют и читают обратно 768 записей из файла Excel.

Новые файлы не стирают локальную SQLite-базу пользователя при обновлении.

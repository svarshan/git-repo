# Инвентаризация · Маяк 2.3 — Умная столовая

WPF .NET 8, SQLite, Excel/Word, каталог из 768 товаров. Полный исходный проект: `Inventarizatsiya/source.zip`.

Четыре основных экрана: Главная, Товары, Пересчёт, Отчёты. Вкладки быстрого ввода и резервных копий остались доступны через контекстные кнопки, чтобы не перегружать меню.

Пересчёт отдельно от учётных остатков: внесённый факт автоматически сохраняется в sqlite-сессию; закрытие пересчёта требует подтверждения и страховочной копии. Реализован безопасный обратный импорт ранее выгруженной ведомости Excel: сверяет все товары и учётные остатки до сохранения, пустые строки не сбрасывают факт.

GitHub Actions выполняет 2 запуска WPF на Windows, открывает разделы, экспортирует и импортирует Excel, проверяет сохранение в SQLite, затем публикует настоящий скриншот окна, автономный EXE и установщик Inno Setup.

Установщик сохраняет пользовательский файл `%LOCALAPPDATA%/Inventarizatsiya/inventory.db`. Прежде чем обновиться, рекомендуется сделать резервную копию через Настройки.

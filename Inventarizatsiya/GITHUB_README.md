# Инвентаризация · Маяк 2.2 PRO

Новая версия WPF с пересчётом остатков в отдельной SQLite-сессии, сохранением черновика, подтверждением факта, Excel-ведомостью расхождений, сроками годности, упаковками, импортом с предварительным подтверждением и автоматическими копиями. Для Windows 10/11 x64.

Сборка: в GitHub Actions выберите workflow на ветке inventarizatsiya-v1. CI выполняет Windows WPF smoke test, два последовательных запуска, реальный программный рендер окна в PNG, проверку пересчёта и Excel, затем создаёт EXE и Inno Setup.

Существующая SQLite-база не удаляется при обновлении. Каталог из 768 товаров остаётся демонстрационным до внесения реальных остатков. Исходники находятся в Inventarizatsiya/source.zip.

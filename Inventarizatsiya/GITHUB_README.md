# Инвентаризация · Маяк 2.1

Версия 2.1: настоящий редизайн — левые кнопки навигации, фото маяка на всю высоту боковой панели, светящийся янтарный акцент. Два встроенных файла Excel с настоящими активными автофильтрами по всем 17 столбцам. Динамические Excel-экспорты также с фильтрами.

Source.zip содержит WPF .NET 8 проект и оба Excel-файла. GitHub Actions компилирует автономный EXE, проводит два запуска с переключением нового левого меню и проверкой фильтров Excel, затем собирает Inno Setup.

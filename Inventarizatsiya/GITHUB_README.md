# Инвентаризация · Маяк 2.5 — Порядок и скорость

Обновление 2.4 на WPF .NET 8. Реализованы пункты 1,2,4,5,6,7,8,9,10. Пункт 3 — сохранение списка ответственных — исключён по требованию пользователя. По-прежнему не добавлены многоскладская система, партии, сканер и автозакупки.

В `Inventarizatsiya/source.zip` исходники, проекты и примеры XLSX. Запуск GitHub Actions собирает EXE, тестирует интерфейс и защиту операций на настоящем Windows-агенте, экспорт Excel, делает скриншот и собирает Inno Setup. База `%LOCALAPPDATA%/Inventarizatsiya/inventory.db` не удаляется. Перед обновлением сохраните резервную копию.

MoOLVa Windows Master 3.1 Portable — предварительная версия
Это C#/.NET Framework 4.8 EXE без PowerShell. Требуются Windows 10/11, .NET Framework 4.8 и установленный Microsoft Edge WebView2 Runtime. Программа сохраняет настройки, профиль WebView и проверенный загрузчик WebView2 в папке профиля Windows; установка MoOLVa не требуется.
ISO Windows 10/11: в окне MoOLVa открывается официальная страница Microsoft. Выберите выпуск и язык. Если Microsoft запросит проверку или недоступен, программа не обходит ограничения сайта. Пользователь выбирает папку для ISO; ссылка может истечь. Встроенный выбор работает при доступности Microsoft/WebView2 и требует сетевой проверки. 32-битные выпуски и языки зависят от Microsoft. Windows 8.1 в каталог не включена.
Мои ISO: путь к выбранной папке и список образов сохраняются в профиле Windows. Для проверки SHA-256 нужно вручную предоставить значение официального источника; без него подлинность не подтверждается.
USB: UEFI, съёмная USB-флешка 4–32 ГБ с одним разделом и серийным номером. Программа форматирует выбранный том FAT32 и уничтожает его данные после двойного подтверждения; защищаются физические диски с MoOLVa, Windows и ISO. Форматирование, запись, разделение install.wim и загрузка НЕ ПРОВЕРЕНЫ на реальной физической флешке. Используйте только отдельный тестовый носитель без нужных данных. install.esd больше 4 ГБ не поддерживается.
Драйверы: Windows Update может не содержать все драйверы. Фильтр прошивок опирается на названия и не идеален. Установка на реальном ПК не проверена.

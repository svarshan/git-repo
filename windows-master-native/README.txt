MoOLVa Windows Master 4.2-preview Portable — предварительная версия
Самостоятельный C#/.NET Framework 4.8 EXE без PowerShell. Нужны Windows 10/11 и Microsoft Edge WebView2 Runtime. Программа сохраняет параметры и служебный профиль в профиле Windows; установка MoOLVa не требуется.

СКАЧИВАНИЕ ISO
На главной выберите «Подготовить Windows и флешку», затем Windows 10 или 11. В окне MoOLVa выберите выпуск, язык и разрядность и нажмите «Скачать ISO». Программа обращается к официальному источнику Microsoft в фоне; страницу Microsoft пользователю показывать не требуется. Для Windows 10 применяется режим совместимости. Списки и ссылки зависят от источника и могут быть временно недоступны. Если Microsoft потребует дополнительную проверку или заблокирует запрос, MoOLVa сообщит об ошибке и не будет обходить ограничения. Прогресс, пауза, продолжение при поддержке и отмена доступны в окне.
После загрузки образ появится в разделе «Мои ISO». Для проверки SHA-256 введите значение из надёжного официального источника; без него подлинность не подтверждена.

ДРАЙВЕРЫ
Поиск, список, сведения, выбор, загрузка и установка выполняются в приложении через Windows Update. Доступность драйверов зависит от модели, версии Windows, сети и политик ПК; Windows Update не гарантирует все драйверы всех производителей. Драйверы с выявленными признаками прошивки блокируются; полностью выявить прошивки автоматически нельзя. Если требуется лицензия, приложение покажет её полный текст и не примет без вашего действия. Реальная установка драйверов на физическом ПК пока не проверена.

ЗАПИСЬ USB
Для UEFI, USB 4–32 ГБ с одним разделом и определяемым серийным номером. Выбранный том форматируется FAT32: все его данные удаляются после двух подтверждений. Физические диски Windows, программы и ISO исключаются. Форматирование и запись тестового ISO проверяются на изолированном виртуальном диске. На физической флешке и при загрузке компьютера НЕ ПРОВЕРЕНО. Используйте отдельный тестовый носитель без нужных файлов. install.esd больше 4 ГБ не поддерживается; разбиение крупного install.wim пока не проверено на реальном образе.

ПРОВЕРКА USB: после копирования файлы сверяются с ISO по SHA-256. Для разделённого install.wim проверяется только наличие первой части install.swm; целостность частей и загрузка с физической флешки не проверены. Проверка может занимать длительное время.

ДОПОЛНЕНИЯ 4.1 PREVIEW
На главной странице показаны память, диски, состояние сетевого интерфейса и устройства с ошибками. Состояние интерфейса не гарантирует доступ в интернет.
В разделе «Карточки и отчёты» можно создавать и сохранять локальные карточки обслуживания. Для отчёта доступны TXT и печать; для PDF выберите «Microsoft Print to PDF» в диалоге печати, если этот принтер установлен в Windows. Карточки хранятся в профиле Windows, а не на флешке с EXE; резервируйте папку %LOCALAPPDATA%\MoOLVa\ServiceCards вручную. История действий относится к текущему сеансу и не заменяет ручное описание выполненных работ.
В окне записи USB доступно сохранение журнала. При загрузке ISO отображается свободное место; если размер образа заранее известен, нехватка места проверяется перед началом. Догрузка после перезапуска программы не гарантируется и зависит от источника.
ОГРАНИЧЕНИЯ: запись по-прежнему поддерживает USB 4–32 ГБ с одним разделом; дополнительные источники драйверов и проверка всех частей разделённого install.wim не реализованы. Полный ISO и загрузка с физического USB не проверены.

ДОПОЛНЕНИЯ 4.2 PREVIEW
Копирование папок: выбирайте отдельный диск. Программа вычисляет примерный объём, проверяет свободное место и сверяет каждый новый файл по SHA-256. Существующие файлы с отличающимся содержимым не перезаписываются и перечисляются как пропущенные. Символьные ссылки и недоступные файлы пропускаются; облачные файлы и заблокированные данные могут не копироваться. Проверьте отчёт. После прерывания повторите операцию с теми же папками и в ту же папку назначения: совпадающие файлы пропускаются. Восстановление выполняется выбранной папкой без автоматического перезаписывания конфликтов.
Установка программ использует установленный WinGet и интернет; доступность пакетов, условия, лицензии, системные политики и установщик зависят от источника. Настройка после установки содержит вручную отмечаемый список, сохранённый в профиле текущей Windows, и ссылки на инструменты.
НЕ ГОТОВО: автоматическая отметка шагов, автоматическое обновление MoOLVa, поиск программ в каталоге, автоматическое получение доверенного эталона для ISO, поддержка USB больше 32 ГБ, проверка всех частей split WIM и дополнительные источники драйверов. Реальные копирование пользовательских данных, установка программ и USB-загрузка не проверены на физическом ПК. EXE требует Windows 10/11, .NET Framework 4.8 и WebView2 Runtime.

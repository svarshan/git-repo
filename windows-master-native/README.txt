MoOLVa Windows Master 4.6 Preview

Portable и установочная сборки для Windows 10/11. Нужны .NET Framework 4.8 и Microsoft Edge WebView2 Runtime. Карточки и параметры сохраняются в профиле Windows, даже при запуске Portable.

WINDOWS И ФЛЕШКА
Скачивание Windows 10 и 11 осуществляется внутри окна программы из источников Microsoft. Доступность выпуска и ссылок зависит от Microsoft и сетевых условий. После полной загрузки программа вычисляет SHA-256; для подтверждения целостности сравните его с доверенным значением самостоятельно.

Запись поддерживает съёмный USB с одним существующим разделом размером от 4 до 32 ГиБ и определяемым серийным номером. Сам носитель может быть больше, если его единственный раздел не превышает 32 ГиБ. Разделы программа не создаёт и не изменяет. Выбранный раздел форматируется FAT32 и все данные на нём удаляются. Мастер дважды просит подтвердить операцию. Режим загрузки UEFI; физическая флешка и фактическая загрузка НЕ проверены.

Обычные файлы после записи сверяются по SHA-256. Для разделённого install.wim проверяются номера, количество и общий идентификатор частей SWM, но целостность содержимого частей не подтверждается. install.esd больше 4 ГиБ не поддерживается. Для безопасности применяйте отдельную тестовую флешку без нужных файлов.

РЕЗЕРВНАЯ КОПИЯ
Создавайте копию на отдельном носителе, который не будет форматироваться. Программа рассчитывает объём и свободное место, копирует и сравнивает файлы по SHA-256. При повторном запуске совпадающие файлы не копируются; отличающиеся существующие файлы пропускаются. Недоступные файлы и ссылки перечисляются в отчёте. Облачные файлы, ссылки, права доступа, альтернативные потоки и открытые файлы могут не сохраниться. Проверяйте отчёт и данные отдельно. Восстановление возможно выбором папки из копии; копии 4.2 и 4.5 выбираются вручную. Копирование личных данных на реальном ПК не проверено.

ДРАЙВЕРЫ И ПРОГРАММЫ
Поиск и установка драйверов зависят от Windows Update и не гарантируют наличие драйверов для всех устройств. Возможные прошивки фильтруются, но фильтр не является полным. Для установки программ нужен WinGet и доступ к его источнику; состав и доступность пакетов могут измениться. Выбранный набор можно сохранить в файл и открыть позже.

ЧТО ЕЩЁ НЕ ГОТОВО
Автоматическое создание подходящего раздела на флешках больше 32 ГБ, проверка содержимого всех SWM-частей, дополнительные встроенные источники драйверов, автообновление MoOLVa, автоматическая отметка всех этапов мастера, категории каталога программ и выбор действий при конфликтах резервных копий. Большие физические носители, полноценные образы ISO, установка программ и драйверов на реальном ПК не проверены.

MoOLVa Windows Master 3.0 Portable — предварительная версия
Это самостоятельное приложение C#/.NET Framework 4.8: PowerShell не используется. Запускайте EXE на Windows 10/11, установка не требуется.
Драйверы: Windows Update предлагает доступные обновления, но может не содержать все драйверы. Прошивки по названию пропускаются, фильтр не идеален — проверьте список перед установкой. Требуются интернет и права администратора.
Windows: средство Microsoft или ISO по временной ссылке Microsoft можно скачать в программе. Выбор языка ISO выполняется на сайте Microsoft. Для ISO можно вычислить SHA-256 и сравнить с официальным значением.
USB: программа записывает файлы только на пустую флешку FAT32, подключенный ISO выбирается как DVD-диск в Windows. Она не форматирует и не очищает накопители. Для install.wim более 4 ГБ применяется DISM, другие файлы более 4 ГБ не поддерживаются. Только UEFI. Подготовку и загрузку реальной флешки необходимо проверить; она пока не тестировалась на физическом ПК.
Проверки GitHub: компиляция EXE, самотесты, запуск приложения и снимок окна на Windows. Реальная установка драйверов, загрузка ISO и USB на физическом ПК не проверялись.

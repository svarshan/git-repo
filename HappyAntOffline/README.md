# Your Happy Ant 1.21.0 — экспериментальный офлайн-APK

Это **тестовая, неофициальная** сборка из исходного XAPK. Скрипт `HappyAntOffline/build_apk.py` собирает один APK из основного приложения, ARM64-библиотек и `asset_pack1`, убирает разрешение INTERNET, отключает обязательное наличие конфигурационных split-пакетов и создаёт новую тестовую подпись Android APK v2.

## Проверенный входной файл

- Имя: `Your+Happy+Ant_1.21.0_APKPure.xapk`
- SHA-256: `7789e080ab81e5dea88fc4cac532b8d203a78a0697a4d7630a7789d531468b48`
- Версия: 1.21.0
- CPU: ARM64 / arm64-v8a

## Сборка через GitHub Actions

1. Откройте вкладку **Actions** → **Your Happy Ant - experimental offline APK**.
2. Нажмите **Run workflow**.
3. Введите **прямой HTTPS-адрес скачивания** именно вашего XAPK (не адрес веб-страницы), затем проверьте SHA-256.
4. После успешной сборки скачайте **Artifacts → Your_Happy_Ant_1.21.0_OFFLINE_TEST**. Внутри ZIP лежит APK.

Рабочий файл XAPK из чата ChatGPT **не загружен в GitHub**. GitHub Actions не сможет получить его по `sandbox:` ссылке. В публичный GitHub-репозиторий не рекомендуется выкладывать сторонние игровые бинарники. Без прямого HTTPS-адреса к исходному XAPK запуск workflow не состоится.

## Ограничения

- ZIP-структура и подпись локальной тестовой сборки проверены. Установка и запуск на реальном устройстве **не проверены**.
- Приложение может не запускаться из-за встроенной проверки целостности Google Play, зависимостей Play Asset Delivery и собственных проверок игры.
- Удаление разрешения INTERNET не делает удалённые сервисы локальными.
- **Бесконечные подсказки и усилители не реализованы.**
- Тестовая подпись отличается от подписи издателя: установка поверх оригинальной игры невозможна; прежде чем удалять оригинал, убедитесь, что прогресс сохранён.
- Разные прогоны GitHub Actions используют разные ключи подписи и **не обновляют друг друга**.

Самостоятельная локальная сборка на компьютере (при наличии Python и библиотеки `cryptography`):

```sh
python -m pip install cryptography
python HappyAntOffline/build_apk.py Your_Happy_Ant_1.21.0.xapk Your_Happy_Ant_1.21.0_OFFLINE_TEST.apk
```

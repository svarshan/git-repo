MoOLVa Windows Master Portable 2.0 PRO — предварительная сборка
Программа запускается без установки на Windows 10/11. Для доступа к дискам и установки драйверов нужны права администратора, для загрузки — интернет и BITS.

USB: мастер предназначен для ISO Windows с загрузкой UEFI (x64 или ARM64); создается MBR/FAT32 раздел до 30 ГБ, файлы свыше 4 ГБ допустимы только в виде install.wim, который разделяется DISM. Все разделы выбранной флешки удаляются. ISO и EXE должны находиться на локальных дисках, отличных от выбранной флешки. Проверка файлов не доказывает загрузку на конкретном ПК. ВНИМАНИЕ: настоящий процесс записи USB пока не проверен на физической флешке, поэтому не используйте этот мастер для важных носителей до практической проверки.

Загрузки: средство Microsoft скачивается в окне программы с проверкой подписи. Для ISO нужно выбрать редакцию и язык на сайте Microsoft и вставить полученную ссылку. Если есть официальный хэш ISO, проверяйте его отдельно. В случае проблем BITS проверьте службы и сеть. Официальная доступность Windows 8.1 может изменяться.

Драйверы: Windows Update может не содержать все драйверы. Проверяйте список и исключайте прошивки; фильтр по названиям не гарантирует их обнаружение. Настоящие поиск и установка драйверов на пользовательском ПК пока не проверены.

Проверки: GitHub Actions проверяет парсинг PowerShell, сборку EXE и запуск окон на Windows, а также выбор драйверов на имитационных данных. Создание USB и установка драйверов на реальном ПК не подтверждены.

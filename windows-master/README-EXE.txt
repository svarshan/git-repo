MoOLVa Windows Master Portable 1.3
Запускайте MoOLVa-Windows-Master-Portable.exe на Windows 10/11 без установки.
Требуются системные Windows PowerShell 5.1 и .NET Framework. Временные файлы программы извлекаются в папку пользователя Temp и удаляются при обычном закрытии.
Для онлайн-поиска драйверов необходим интернет и согласие на повышение прав администратора. Драйверы предлагаются Windows Update; могут быть доступны не все устройства. Список требует проверки, особенно на наличие прошивок; поиск их по названию не безошибочен.
Создание установочной флешки происходит через отдельное официальное средство Microsoft. При записи данные на выбранной флешке удаляются. Используйте отдельную флешку для MoOLVa и не выбирайте ее в средстве Microsoft.
Приложение не создает интернет-соединение без исправного сетевого оборудования и драйвера. Сохраните нужные файлы перед перезагрузкой. Запуск в GitHub Actions не заменяет проверки установки драйверов и подготовки носителя на настоящем ПК.

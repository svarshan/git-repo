MoOLVa Windows Master Portable 1.4 PRO
Запустите EXE на Windows 10/11. Устанавливать MoOLVa не нужно. Нужны Windows PowerShell 5.1 и .NET Framework.
Раздел «Подготовить Windows»: загрузка Media Creation Tool Windows 10/11 или ISO по полученной на сайте Microsoft временной ссылке. Загрузку выполняет BITS. Выбор редакции и языка ISO пока выполняется на сайте Microsoft. Программа проверяет цифровую подпись скачанного средства Microsoft перед сохранением. Для ISO нужна собственная проверка хэша Microsoft.
Запись установочного USB выполняется отдельным средством Microsoft, которое нужно запустить самостоятельно. Будут удалены все данные с выбранной флешки. Храните MoOLVa на другом носителе.
Раздел «Настроить компьютер»: окно поиска доступных драйверов Windows Update. Подтвердите UAC, проверьте список и выберите драйверы; при работе видны этапы, результат, можно сохранить отчет. Известные прошивки по названию исключаются, но автоматический фильтр ненадежен: вручную проверяйте список. Обновления с непринятой лицензией пропускаются. Полный каталог драйверов разных производителей не гарантирован; для отсутствующих используйте официальный сайт производителя.
Работа драйверов и ISO зависит от подключения к интернету, служб BITS и Windows Update, настроек организации и доступности источника. Сетевой драйвер иногда нужно загрузить на другом компьютере.
Проверка: GitHub Actions проверяет синтаксис, компиляцию, базовый запуск GUI; поиск/установка драйверов и создание USB на настоящем ПК не тестировались.

# MoOLVa Грибы 3.4

Portable Windows x64 включает обзорную офлайн-карту и офлайн-индекс населённых пунктов. Более подробные пакеты шести географических участков загружаются через меню карты, проверяются по SHA-256 и сохраняются в профиле приложения. Прерванную загрузку можно продолжить.

Пакеты содержат данные OpenStreetMap contributors · Protomaps Basemap (ODbL 1.0 Produced Work). Каталог с контрольными суммами и атрибуция публикуются вместе с пакетами. Границы участков являются границами картографического покрытия.

Для сборки в Windows используйте GitHub Actions. Подготовка данных повторно использует атрибутированные материалы из проверенного релиза 3.3. Команда `npm test` запускает проверки исходников и скачивания пакетов. Windows job дополнительно запускает сам Portable EXE и проверяет офлайн-карту.

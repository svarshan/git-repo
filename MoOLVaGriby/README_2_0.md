# MoOLVa Грибы 2.0 PRO MAX — этапы реализации

Резерв предыдущей успешной версии: **backup/moolva-griby-1.0-before-2.0-20261116**. Приложение «Птицы» не меняется.

## Включены 15 направлений

1. Энциклопедия на **цель 300 видов**: только найденные в опубликованных наблюдениях сообщества iNaturalist с научным названием и ссылками; число не подгоняется искусственно. Базовые 53 карточки сохранены.
2. Фотоатлас с источниками, лицензиями и дополнительными ракурсами у видов, для которых они найдены. Не заявлять 3–6 кадров для всех.
3. Сопоставление опасных двойников, базовая сравнительная таблица.
4. Полевой определитель по признакам (кандидаты, **не определение на съедобность**).
5. Помощник по загруженным фотографиям — **экспериментальное сравнение цветовых палитр без обученной AI-модели**. Полноценная AI-модель пока не реализована.
6. Координатная схема опубликованных наблюдений региона плюс приватные точки пользователя. Нет сетевой подложки и вымышленных GPS-точек.
7. Календарь с ориентировочными месяцами и частотами опубликованных наблюдений (без прогноза урожая).
8. Дневник 1.0 сохранён; экспорт CSV для Excel, JSON и печать в PDF через Windows.
9. Интерактивная схема строения гриба.
10. Кнопка «В лесу» включает увеличенные элементы управления, минимум отвлечений.
11. Статистика личного дневника по годам и видам.
12. Раздел охраняемых видов, **без выдуманных статусов Красной книги**. Нужна официальная сверка.
13. Оптимизация: ограниченная первая отрисовка, lazy images, обособленные страницы.
14. Контроль лицензий, отсутствующих фото, экспорт отчёта и указание непроверенного визуального соответствия.
15. Windows Setup и Portable EXE с реальными smoke screenshots, SHA256SUMS, релизным workflow и опциональной проверкой публичных версий.

## Лицензии

Фотографии Wikimedia Commons и iNaturalist включаются только при подходящих лицензиях, сохраняются авторы и ссылки. Наличие соответствующего научного названия в метаданных **не означает** визуальной проверки на точность.

## Геоданные и безопасность

Схема отображает **лишь публичные** наблюдения исследовательской категории сообщества iNaturalist, строго с валидными открытыми координатами внутри указанной широкой географической рамки. Точные местоположения скрытых и охраняемых объектов исключаются из импорта. Это не научная верификация, не подсказка «где собирать».

## Данные пользователя

Хранилище 1.0 `moolva-griby-1.0-data` не перезаписывается при обновлении. Перед восстановлением резервной копии спрашивается подтверждение. Все загружаемые личные фотографии обрабатываются локально и не передаются внешним сервисам.

## Известные ограничения

Цель 300 видов зависит от фактической доступности данных; безопасное снижение до 53 сохранено при ошибках API. Фотоатлас не гарантирует 3–6 ракурсов для каждого вида. Нет научно валидированного AI-распознавателя по фото, настоящей картографической подложки и официально подтверждённого полного перечня Красной книги. Программа никогда не должна делать вывод, что гриб пригоден в пищу.

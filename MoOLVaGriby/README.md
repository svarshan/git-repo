# MoOLVa Грибы 2.0 PRO MAX

Документация текущей версии: [README_2_0.md](README_2_0.md).

Сохранена исходная версия 1.0 в резервной ветке `backup/moolva-griby-1.0-before-2.0-20261116`.

Работа программы полностью офлайн после сборки. Фотографии и геоданные пополняются в процессе Windows CI из лицензированных источников, но могут отсутствовать, если источники недоступны. Ни визуальное сходство, ни признаки не подтверждают съедобность найденного гриба.

Поддерживаются Setup и Portable для Windows x64. Публичные файлы появятся в GitHub Releases только после слияния проверенного PR в master и успешной сборки на master; до этого скачивание доступно через GitHub Actions либо вложения ChatGPT.

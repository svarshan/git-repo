# MoOLVa Грибы 1.0 PRO MAX 🍄

Самостоятельное образовательное приложение для Windows 10/11 и современных браузеров, разработанное в отдельной папке **MoOLVaGriby/**. Исходные файлы MoOLVa Птицы не меняются.

## Реализовано

- 53 описанные карточки грибов средней полосы (не утверждение о региональном присутствии каждого вида).
- Поиск по-русски и по латыни, группы, сезон, известные ядовитые виды.
- Фотографии из Wikimedia Commons и iNaturalist, когда есть найденный лицензированный файл и корректные метаданные; автор и лицензия в карточке. Фото из неподтверждённого источника не подставляется.
- Похожие виды, сравнение двух видов, озвучивание через системный русский голос Windows.
- Избранное, дневник грибника, личные места и резервная копия JSON — полностью локально.
- Отдельный центр проверки фотографий и честные пометки о непроверенной визуальной идентификации.
- Windows Setup EXE и Portable EXE через GitHub Actions после фактической успешной сборки; настоящий скриншот приложения.

## Безопасность

Ни картинка, ни признаки, ни любые алгоритмы не могут удостоверить, что найденный гриб безопасен для еды. Даже съедобные по литературе виды имеют ядовитых двойников. Не употребляйте дикорастущие грибы без личной проверки квалифицированным специалистом. При подозрении на отравление срочно обращайтесь за помощью, не ожидая симптомов.

Источники общего предупреждения: https://www.poison.org/articles/wild-mushroom-warning и https://poisons.ie/garden-shed/ .

## Запуск

- **Без установки:** открыть `index.html` в браузере (если фотографии ещё не загружены, заглушки честно покажут отсутствие).
- **Разработка:** в папке MoOLVaGriby выполнить `npm install`, `npm start`.
- **Windows EXE:** в GitHub Actions открыть workflow **MoOLVa Griby — Windows Setup и Portable**, скачать ZIP-артефакты, извлечь EXE.

## Фото и права

`scripts/fetch_commons.py` принимает только совместимые свободные лицензии Creative Commons/общественное достояние, сохраняет JPEG-миниатюры и авторство. Название категории недостаточно для экспертного определения вида — для всех новых фото статус **нужна визуальная проверка**. При ошибках сети приложение не подставляет поддельные фото.

## Развитие

Будущие версии: подтверждённые региональные наблюдения, географическая карта, экспертный реестр фотографий, определитель по признакам. Распознавание по фото не реализовано в 1.0 и не должно заявляться как действующая функция.

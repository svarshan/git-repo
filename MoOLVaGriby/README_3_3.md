# MoOLVa Грибы 3.3 PRO MAX — карта в главном меню

## Что изменено по жалобе «Нет пункта Карта грибных мест»

1. **«🗺 Карта грибных мест» — постоянный пункт главного меню**, второй сверху сразу после «Атлас грибов». Он зашит в HTML и виден до загрузки JavaScript.
2. **Сам раздел карты тоже есть в HTML с самого запуска.** При успешной загрузке карты старый модуль «Экспедиция» расширяет его фильтрами, отчётами, точками и импортом GPX. Если старый модуль даст сбой, новая карта запускается из резервного экрана.
3. На главной странице атласа есть дополнительная кнопка **«Открыть карту грибных мест»**.
4. Основной слой — Leaflet 1.9.4 и OpenStreetMap, бесплатно и без Google API. Названия населённых пунктов, дороги и леса загружаются из интернета.
5. Масштабирование колёсиком мыши, настоящие кнопки +/−, перетаскивание. Реальная карта проверяется в запущенном Windows EXE.
6. Google Maps / спутник перенесён **ниже бесплатной карты**. Без ключа можно открыть карту в официальном браузере, встроенный Google JS API остаётся необязательным.
7. Вкладка **«Мои места»** — это старый список личных записей; **«Карта грибных мест»** — реальная новая географическая карта.
8. Сохранены каталог, фотографии, дневник, GPX/JSON и прежние ключи localStorage. Перед обновлением рекомендован экспорт резервной копии.

## Как запустить

1. Закройте все открытые окна MoOLVa Грибы, чтобы старая версия не продолжила работать через single-instance.
2. Запустите **MoOLVa-Griby-3.3-Portable-x64.exe** либо установите **MoOLVa-Griby-3.3-Setup-x64.exe**.
3. На первом экране слева сразу под «Атлас грибов» найдите **«🗺 Карта грибных мест»**. Можно также нажать кнопку карты на главной странице.
4. Нужен интернет для загрузки настоящей карты: масштабируйте колёсиком, перемещайте мышью, используйте +/− и поиск по известным районам.
5. При отсутствии карты проверьте интернет и доступ к https://tile.openstreetmap.org. Запасной вариант — «Открыть OpenStreetMap» и ссылка браузера в резервном экране.
6. Для просмотра спутника Google выберите отметку и нажмите «Спутник Google без ключа»; откроется браузер.

## Что было проверено

Windows GUI проверка обязана завершиться ошибкой сборки, если:
- второй пункт главного меню отсутствует, не виден в окне или не имеет заголовка «Карта грибных мест»;
- раздел карты отсутствует в статической HTML-странице;
- нажатие по пункту меню не переводит на страницу карты либо Leaflet не становится видимым;
- не работают настоящие кнопки увеличения/уменьшения Leaflet;
- отсутствует скриншот интерфейса \`08-visible-map-menu.png\`.

## Безопасность

Оранжевые круги соответствуют опубликованным **примерным районам**, а не настоящим грибницам. Личные координаты хранятся локально. Научно-гражданские записи iNaturalist не гарантируют повторного появления грибов. Определение вида или съедобности по карте невозможно.

# MoOLVa Грибы 3.2 PRO MAX — бесплатная карта населённых пунктов

## Для пользователя

Откройте **Экспедиция 3.2**. Карта теперь автоматически использует **Leaflet + OpenStreetMap** вместо старой упрощённой координатной схемы. Для показа дорог, населённых пунктов и лесных дорог нужен интернет, но **никаких API-ключей, регистрации Google Cloud или банковской карты не требуется**.

- Колесо мыши или кнопки `+` / `−` — приближение и отдаление от масштаба 5 до 19.
- Удерживайте левую кнопку мыши и перемещайте карту.
- Нажмите на пустое место карты: координаты автоматически появятся в форме «Мои грибные места». Укажите название и нажмите «Сохранить».
- Введите название одного из известных районов (например, Бор или Фролищи) в поиск над картой; можно перейти к населенному пункту.
- Нажмите «Вся область», чтобы вернуться к общему виду Нижегородской области.
- «Открыть OpenStreetMap» запускает карту в браузере. На выбранной отметке по-прежнему работают ссылки на Google Maps и спутниковые карты Google без ключа.
- Все личные записи, JSON/GPX, фото, дневник и каталог от 3.1 сохраняются без миграции.

## Откуда берутся отметки
- **Оранжевые**: 12 публично описанных районов находок грибов около населённых пунктов. Круг показывает примерный радиус, не точную поляну.
- **Зелёные**: обобщённая сетка открытых наблюдений сообщества iNaturalist (примерно 10–20 км на ячейку).
- **Фиолетовые**: *только при включении соответствующего фильтра* открытые публикации с заявленной точностью GPS 1–100 м по отдельным распространённым видам; это не гарантия нахождения грибов.
- **Голубые**: введённые вами личные координаты; остаются на устройстве.

Открытые источники не подтверждают безопасность еды или наличие грибов сейчас. Скрытые координаты и координаты охраняемых видов не импортируются.

## Что меняется технически

- Встроенная локально библиотека Leaflet 1.9.4 (`node_modules/leaflet/dist/*`) работает и без сети.
- При открытии карты онлайн загружаются только необходимые текущему виду тайлы `https://tile.openstreetmap.org/{z}/{x}/{y}.png`. Нет массового скачивания и офлайн-кэширования. Приложение передаёт собственный User-Agent; HTTP-кэш не отключается.
- Обязательная ссылка на © OpenStreetMap contributors выводится на карте.
- Если нет интернета, кнопка «Открыть OpenStreetMap» и локальные точки остаются доступны для восстановления доступа; координатная схема версии 3.1 сохранена как резерв.
- Google Maps JavaScript API всё ещё может быть подключён отдельным ключом и Google Cloud Billing, однако в Electron `file://` могут не работать ограничения HTTP-referrer. Поэтому ключ не является основной опцией.
- Подписи на тайлах зависят от картографических данных OpenStreetMap. Полноценной спутниковой подложки Google без ключа внутри EXE нет. Для спутника нажмите «Спутник Google без ключа», который откроет официальный Google Maps в браузере.

## Протокол проверки

- `npm test` и тесты Python, проверка исходного JS.
- Проверка локальной библиотеки Leaflet внутри упакованного EXE.
- Настоящий запуск GUI Windows и проверка, что экран экспедиции показывает Leaflet map, слои, надпись об авторстве и что `map.zoomIn()` действительно увеличивает zoom.
- Скриншот `07-free-interactive-map.png`, `free-map32-smoke.json` и контрольные суммы SHA-256 в QA-пакете.
- Доступность внешних OSM-тайлов из CI не является доказательством их доступности у каждого пользователя; провайдер может временно ограничивать или блокировать запросы.

## Правила использования

- OSMF Tile Usage Policy: https://operations.osmfoundation.org/policies/tiles/
- Документация Leaflet: https://leafletjs.com/examples/quick-start/
- Данные OSM и лицензия: https://www.openstreetmap.org/copyright

В бесплатной публичной версии нельзя гарантировать коммерческую SLA OpenStreetMap. Для больших нагрузок следует подключать собственный тайловый сервер или провайдера с подходящими условиями.

# MoOLVa Грибы 3.1 PRO MAX — Google Maps

Исходная версия: 3.0 «Экспедиция» (ветка master, резерв `backup/moolva-griby-3.0-before-google-20261117`). Обновление добавляет Google Maps без удаления данных 3.0.

## Что работает без Google API-ключа
- Вся карта версии 3.0 с 12 приблизительными районами публичных сообщений о грибах, обобщёнными наблюдениями iNaturalist и вашими точными личными GPS-точками.
- Кнопки «Выбранная точка в Google Maps» и «Спутник Google без ключа». Первая открывает официальную Google-карту с маркером координат, вторая — спутниковую карту по тому же центру на масштабе 16; обе работают в браузере без ключа и тарификации Maps JavaScript API.
- Отметка не становится точной от открытия на спутниковой подложке. Для 12 сообщений о находках 2026 года хранятся ориентиры населённых пунктов с приблизительным радиусом, а не координаты полян.
- Личные GPS-точки сохраняются в прежнем localStorage ключе `moolva-griby-v3-private-points`; форматы JSON/GPX не изменены.

## Опциональная встроенная Google Maps
1. Google Cloud Console: включите **Maps JavaScript API** и Billing, получите отдельный ключ.
2. Откройте в Windows-приложении «Экспедиция 3.0» -> «Google Maps · спутник и настоящие дороги».
3. Вставьте свой ключ в поле, нажмите «Показать спутник Google». Дайте согласие на передачу обращений Google и возможную тарификацию.
4. Карта покажет дороги и спутник. Оранжевые круги — **примерные окрестности** публикаций (их радиус отличается); зелёные точки — **обобщённые** наблюдения; голубые — личные GPS.
5. Вы можете нажать на Google-карту, чтобы автоматически вписать точные координаты в форму «Мои грибные места», затем назвать точку и сохранить.
6. «Офлайн-карта» скрывает Google, возвращая координатную схему с прежними данными.

### Важная оговорка для desktop Electron
Google прямо предупреждает, что в приложениях, загружающих JS из `file://`, HTTP referrer может отсутствовать, из-за чего ограниченные ключи не проходят проверку. Не существует безопасного способа вложить общий ключ в публичный EXE; его можно извлечь и использовать для чужих запросов. На экране предусмотрены собственный ключ пользователя и управление квотами; **в этой desktop-версии работа встроенной Google JS карты зависит от ограничений ключа и не гарантируется**. Надёжный вариант без ключа — открытие точек по официальным Google Maps URLs. Для коммерческой защищённой интеграции рекомендуется отдельный HTTPS-веб-хост с корректным HTTP referrer и ключом с ограничениями.

Google Maps Platform подлежит оплате; проверяйте актуальные тарифы. Встроенные Google-карты только онлайн, тайлы не загружаются заранее, не кэшируются и не включаются в EXE.

## Дополнительный слой публичных GPS-наблюдений

В режиме Google имеется чекбокс «Публичные GPS-наблюдения распространённых грибов» (по умолчанию выключен). Список открыт также без Google API-ключа — можно выбрать наблюдение и нажать «Показать в Google Maps».
- Только открытые research-grade наблюдения iNaturalist, у которых указан показатель `positional_accuracy` от **1 до 100 метров**, дата и оригинальная ссылка.
- Белый гриб (`Boletus edulis`), подберёзовик (`Leccinum scabrum`), лисичка настоящая (`Cantharellus cibarius`), маслёнок настоящий (`Suillus luteus`) и маслёнок зернистый (`Suillus granulatus`): ограниченный список широко распространённых таксонов, не универсальная база грибов.
- Отброшены скрытые/obscured координаты и записи без точности; остальные iNaturalist отображаются только обобщёнными ячейками.
- Точность означает точность *предоставленного геотега*, а не научное подтверждение находки и не гарантию наличия грибов сейчас.
- Число точных GPS-наблюдений зависит от фактически полученных данных региона в момент сборки; при нулевом количестве виден честный пустой список.

## Защита координат и достоверности
- Сведения из соцсетей и пересказов СМИ — исторические, не являются проверенным актуальным точным GPS-местом.
- Гражданские наблюдения iNaturalist остаются обобщёнными. Закрытые и охраняемые координаты НЕ показываются.
- Точные личные GPS остаются локально до их явного открытия через Google; при этом открытая Google-карта может передавать данные о местности и пользовательских взаимодействиях Google.
- Никаких гарантий урожая и съедобности; карта используется исключительно для изучения и ориентирования.

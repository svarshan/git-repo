# MoOLVa 7.0 — «Полевой атлас PRO»
## Обязательное ТЗ для развития исходной Windows Electron-энциклопедии

Дата: 24.10.2026. Статус: согласованный набор требований, **не отчёт о готовом EXE**.

### Неприкосновенная база
Работать с `PtitsyNN/` репозитория `svarshan/git-repo`, а НЕ создавать новую оболочку Edge или прототип вместо приложения. Сохранить UI версии 5.0, каталог 298 видов, загруженные лицензированные фото, аудио, паспорт, Академию, дневник, избранное, резервное копирование. Переносимые данные пользователя не удалять. Не объявлять EXE готовым без успешной сборки и проверки.

### P0-A: Настоящая географическая карта области
1. Настоящий контур Нижегородской области, проверенный офлайн-источник границ; фон рельефа/местности только с правомерно включёнными данными.
2. Панорамирование, управляемый zoom относительно курсора, сброс позиции, управление с клавиатуры, адаптивность на 1366×768.
3. Все известные обобщённые точки встреч из источников вроде GBIF, с месяцем/периодом, количеством сообщений, источником и датой выборки. Различать *подтверждённые находки* и *потенциальное место обитания*; не интерпретировать отсутствие записей как отсутствие вида.
4. Фильтры: вид, систематическая группа, месяц, сезон, категория охраны, наличие фото/голоса.
5. При наведении/нажатии — фото, русское/латинское имя, запись голоса, ссылка на паспорт, источник и диапазон лет.
6. «Показать на карте» из паспорта и Bird AI; «Открыть паспорт» из всплывающей карточки.
7. Скрыть или укрупнять чувствительные координаты охраняемых видов, не публиковать геоточки гнёзд. Учитывать `coordinateUncertaintyInMeters`, GBIF geospatial flags, лицензии и дату наблюдения.
8. Карта и фильтры полноценно работают **без сети**. Учитывать что импортированные личные точки видны только пользователю и не выдаются за проверенный публичный источник.

### P0-B: Настоящий Bird AI Google Perch v2
1. Применять реальные лицензированные Apache-2.0 ONNX-веса Perch v2 и неповреждённые labels/metadata, верифицируя SHA-256. Восточноевропейская региональная сборка (739 классов) или обоснованное более широкое покрытие; нельзя утверждать, что все 298 местных видов входят в 739 меток без сверки названий.
2. Полностью локальное распознавание после установки, **никаких** облачных запросов и вымышленных результатов.
3. Загружать WAV, MP3, FLAC, OGG; декодировать в mono 32kHz; вырезать/просматривать последовательные пятисекундные окна; измерять качество сигнала и выводить результаты каждого окна и всей записи.
4. Запись с микрофона (10/30/60с) по явному разрешению пользователя, понятная кнопка «Стоп», выбор устройства, информирование об использовании микрофона. В `main.cjs` сейчас разрешения запрещены по умолчанию — исправить строго для запроса `media` от локального доверенного окна и при пользовательском действии; прочие разрешения сохранить запрещёнными.
5. Ранжированные прогнозы, сравнение с голосами справочника, сопоставление научных таксонов модели и каталога с учётом синонимов, разрешение «нет подходящего вида» или «не удалось определить».
6. Не называть softmax «достоверностью»: региональная модель нормирует оценки на своё множество классов. Вывести предупреждение о необходимости подтверждения.
7. «Открыть паспорт», «Показать на карте», «Добавить в дневник» для результата.
8. Сохранённая модель с доказанными лицензией, авторством, SHA256 и запущенным smoke test. CPU-инференс на Windows x64 обязателен. При отсутствии модели приложение сообщает правду и не подставляет догадки.

### P1: Энциклопедия MAX
- Улучшить структурированный паспорт: размеры, оперение, сезонность, корм, голос, биотопы, ареал, размножение, охрана, источники — только верифицированные.
- Честные метки «фото есть», «голос есть», «подробная статья», «сведения не проверены» на карточках.
- Сравнение двух видов с независимым воспроизведением аудио, изображениями и пересечением/различием карт наблюдений.
- Фото/аудио: проверенные источники, запись лицензионных данных и лог технического аудио-аудита.

### P1: Полевая работа
- Дневник с датой, временем, заметкой, численностью, вложениями; импорт и экспорт JSON и CSV без потери личных данных.
- Локальное сохранение найденного через AI вида с возможностью ручного исправления.
- Один экран без лишней перегрузки, высокая скорость поиска, русская локализация, навигация назад.

### P0: Правила выпуска
- GitHub Actions собирает **два** файла: `MoOLVa-7.0-Setup-x64.exe` и `MoOLVa-7.0-Portable-x64.exe`.
- В релиз включается проверенная настоящая модель (если это предусмотрено пакетом). Если модель отсутствует, выпуск со статусом «Bird AI готов» запрещён.
- Автотесты: синтаксис JS/Python, все 298 видов, локальные фото и аудио, офлайн карта и месячный фильтр, клики в паспорта, тест модели с реальным ONNX inference, микрофонный интерфейс/правила разрешений, распаковка обоих EXE.
- Проверять поведение на Windows на реальном компьютере до заявления «полностью протестировано».
- Сохранить слепок исходников **до** сборки и новый невзаимозаменяемый GitHub Release после проверок; ни один прежний Release/архив не перезаписывать.
- Portable хранит свои настройки/дневник предсказуемо, предоставляет перенос из резервной копии 5.0, данные при обновлении не удаляются.
- В финальном отчёте отдельно указать фактическое число проверенных фото, голосов, видов в модели и географических наблюдений.
- Невыполненные пункты оставить обозначенными как «не реализовано», не выдавать исходники или HTML за готовый EXE.

### Приоритет работ
1. Релизная воспроизводимость GitHub + сохранение исходной 5.0.

3. Bird AI: модель ONNX в EXE, микрофон, длинные файлы, результаты, маршруты к паспортам/карте.
4. Энциклопедия, сравнение, медиа и полевой дневник.
5. Полный тест Windows и публикация двух файлов в GitHub Releases.
